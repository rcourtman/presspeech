Windows prerelease

Private dictation on your Windows PC

Hold Right Alt or choose Press to toggle, speak, and release. Presspeech transcribes locally on your PC, verifies the original destination before automatic paste, and opens Delivery Recovery if the target cannot be confirmed. No account or cloud transcription.

Current published Windows prerelease: 0.1.14. Install metadata updated 23 November 2026.

Download and verify 0.1.14 Release notes and checksum First dictation guide Install with an assistant

Model download and privacy (Windows 0.1.14): Setup asks before downloading missing first-run speech models and offers Set Up Later. Bundled Hub telemetry and account-token authentication are disabled before imports, hf-xet is bypassed, and every inference file is rehashed against pinned SHA-256 digests before loading. Windows 0.1.14 uses pinned huggingface-hub 2.4.0 with httpx2 2.16.2 and default trust_env=True, so configured HTTP_PROXY, HTTPS_PROXY, ALL_PROXY, NO_PROXY, SSL_CERT_FILE, and SSL_CERT_DIR settings still apply. Review the trust of any TLS-inspecting HTTPS proxy before downloading. Dictation audio and transcripts are never sent. See the version-specific network inventory.

This prerelease is not code-signed. Windows may show Unknown publisher, and managed PCs or Windows 11 Smart App Control may block it. Microsoft documents that Smart App Control has no per-app exception. Verify the SHA-256 checksum from this repository before running the installer, and never bypass a policy block.

Historical notice for Windows 0.1.12

Published Windows 0.1.12 started its first model download automatically on launch without Setup deferral, briefly checked the microphone automatically in Setup, and left bundled Hub/Transformers telemetry and implicit authentication enabled on pinned Hub 1.29.0 / HTTPX 0.28.1 (including HF_TOKEN, HUGGING_FACE_HUB_TOKEN, inherited HF_ENDPOINT/HUGGINGFACE_CO_STAGING routing, HF_HUB_USER_AGENT_ORIGIN, and /api/agent-harnesses). Published Windows 0.1.12 also did not independently verify model files against SHA-256 or set Windows Clipboard History exclusions.

Already used Windows 0.1.12? If a model download ran with a token available and an inherited HF_ENDPOINT or staging setting may have routed it to an untrusted destination, or an untrusted TLS-inspecting HTTPS proxy could read the request, treat the token as disclosed and revoke and replace it at Hugging Face Access Tokens. Never include token values in logs or support requests. If waiting to upgrade an existing install, turn off Presspeech in Settings → Apps → Startup without reopening 0.1.12.

Install safely

Download, verify, and run

Presspeech remains compatible with Windows 10 x64, though Microsoft ended general Windows 10 support on 14 October 2025. Prefer Windows 11, or use Windows 10 only with Extended Security Updates or a supported edition.

  1. Download the current installer and checksum

    Get Presspeech-Setup-0.1.14-x64.exe and its published SHA-256 file from the same GitHub release.

  2. Verify SHA-256 automatically

    In PowerShell from your Downloads folder, validate the checksum file and compare it with the installer. Because both files come from the same release, the checksum confirms integrity rather than publisher identity.

    $installer = '.\Presspeech-Setup-0.1.14-x64.exe'
$parts = (Get-Content -LiteralPath "$installer.sha256" -Raw).Trim() -split '\s+'
if ($parts.Count -ne 2 -or
    $parts[0] -notmatch '^[0-9a-fA-F]{64}$' -or
    $parts[1] -ne (Split-Path $installer -Leaf)) {
  throw 'The published checksum file is not valid. Do not run the installer.'
}
$actual = (Get-FileHash -LiteralPath $installer -Algorithm SHA256).Hash
if ($actual -ne $parts[0]) {
  throw 'SHA-256 verification failed. Do not run the installer.'
}
"SHA-256 verified: $actual"
  3. Optionally verify the immutable release attestation

    If you use an authenticated GitHub CLI, you can also check GitHub's signed release attestation:

    $ErrorActionPreference = 'Stop'
gh release verify windows-v0.1.14 --repo rcourtman/presspeech
if ($LASTEXITCODE -ne 0) { throw 'Release attestation failed; do not run the installer.' }
gh release verify-asset windows-v0.1.14 $installer --repo rcourtman/presspeech
if ($LASTEXITCODE -ne 0) { throw 'Installer attestation failed; do not run the installer.' }
'Release and installer attestations verified.'

    The success line prints only if both commands succeed. If either fails, stop and do not run the installer.

  4. Run the installer

    Because this build is unsigned, Microsoft Defender SmartScreen may show Windows protected your PC. Confirm the filename and verified hash before choosing More info → Run anyway. That applies only to SmartScreen reputation warnings, not Smart App Control or administrator blocks.

  5. Decide whether to launch 0.1.14

    Downloading or installing without opening the app makes no network request. If you want to wait, clear the installer’s final Launch Presspeech checkbox (it starts checked by default) and do not open the app. If you choose to use 0.1.14 now, launch after reviewing the model-download privacy note. Setup asks before fetching missing first-run models.

Why the warning? Microsoft explains that unsigned downloads start without publisher reputation, so each new unsigned version may prompt again.

First launch

First launch of Windows 0.1.14

Read the model-download privacy note before opening the app. Windows 0.1.14 asks before downloading missing first-run model files, and Set Up Later defers that request. A complete cached model loads offline.

  1. Choose model preparation or defer

    With usable NVIDIA CUDA, the fresh default is multilingual Parakeet (~2.5 GB), with the smaller CPU model also offered. Without CUDA, the default is English-only Whisper base.en (~141 MiB). Other models remain available in Settings.

  2. Choose input and dictation style

    Select your microphone and hotkey, and choose Hold to talk or Press to toggle in Setup. Right Alt is the default, or pick F8 if Right Alt acts as AltGr. A new profile starts with Start Presspeech with Windows off, while existing saved choices are kept.

  3. Check the microphone explicitly

    Choose Check Microphone to open the selected input briefly for a local level test. Changing the selected input does not start capture, and samples are discarded in memory. Use the Windows Microphone Privacy and Sound Input links if no level appears.

  4. Finish or defer Setup

    Try Dictation opens once the model is ready, and Finish Setup also requires the global hotkey listener. Set Up Later closes Setup incomplete and reopens it on the next launch.

Everyday use

Hold, or press to toggle

Dictate in your apps

Hold Right Alt by default, speak, and release, or switch to Press to toggle in Setup or Settings. Presspeech shows Connecting microphone… until the first buffer arrives, plays its ready cue, and begins listening. Press Escape to cancel without touching the clipboard. If the global key stops responding because Windows silently removed the low-level hook, choose Repair Global Hotkey from the tray menu or Settings.

Window focus and Delivery Recovery

Each recording is bound to the window where it started. If focus changes, the target runs as administrator (Windows blocks standard-app SendInput), a browser tab title or focused UI Automation Edit element changes, or keyboard delivery is uncertain, Presspeech skips automatic paste and opens Delivery Recovery with explicit Copy, Discard, and Leave Waiting actions. Known-invalid targets leave your prior clipboard intact. Keep the starting field and tab focused until delivery finishes.

Review commands before running them

PowerShell, Command Prompt, Windows Terminal, and remote consoles are execution surfaces that can run pasted newlines immediately. The default suffix is space, not newline. Dictate commands into Try Dictation or a plain-text editor, review them, and paste deliberately. See Windows Terminal paste warnings.

Clipboard history and sync

Normal and recovery delivery write finished text to the Windows clipboard and replace the current item without restoring it afterward. Windows 0.1.13 and later add Microsoft's ExcludeClipboardContentFromMonitorProcessing format before every dictation clipboard write, asking Windows not to retain it in Clipboard History or Cloud Clipboard. The current clipboard remains readable by local apps for Ctrl+V and by third-party clipboard managers.

Remote desktop aware

Microsoft Remote Desktop uses redirected plain-text clipboard delivery when client and host policy permit, while Moonlight uses its client-side clipboard-typing shortcut. Test harmless text in a disposable remote editor before relying on either route. Standard local Windows apps keep the normal Ctrl+V path.

Updates require approval

Optional update checks read public GitHub release metadata and ignore releases not marked immutable. Automatic checks notify quietly in the tray menu (Review Available Update…) so they never interrupt dictation. Presspeech downloads an installer only after approval and verifies its size and SHA-256 before offering to run it.

Privacy

Speech stays on the PC

No transcription service

Speech recognition runs locally after model files download from pinned Hugging Face revisions. Windows 0.1.13 and later fix the public endpoint, disable bundled Hub telemetry and implicit authentication, bypass hf-xet, and rehash every inference file against pinned SHA-256 digests before loading. There is no Presspeech account, analytics SDK, crash reporter, or transcript history.

Diagnostics omit your words

Copy Diagnostics reports runtime state, timings, and character counts locally without sending anything. It excludes transcript text, audio, and dictionary contents.

See the privacy page and machine-readable network-call inventory for the complete cross-platform network surface.
