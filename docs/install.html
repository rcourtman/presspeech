Install

Install Presspeech on macOS

Use the direct notarised download for the shortest path, or Homebrew if you want command-line install and updates. The app then guides model loading, macOS privacy grants, and hotkey readiness from Setup Checklist.

Current published macOS release: 0.3.8. Install metadata updated 23 September 2026.

Before installing or launching macOS 0.3.8: its model-download requests may include a Hugging Face token inherited by Presspeech. The public model needs no account token. If a token may be present in the environment that launches Presspeech—or you are unsure—wait until macOS 0.3.9 is published. Downloading the macOS ZIP from GitHub does not make a model request; the first download of a missing model starts when the app launches, so you can keep the downloaded app unopened while waiting. Dictation audio and transcripts are not sent in these requests. See the version-specific network inventory.

Already used macOS 0.3.8? See what to do before another model download.

Using Windows? The Windows install guide has the current prerelease installer, system and model sizes, SHA-256 verification steps, and first-run instructions.

Fast path

Direct download

  1. Download the app

    Download Presspeech 0.3.8 (.zip) from the current GitHub release.

  2. Optionally verify the archive

    In Downloads, verify the current archive against its published SHA-256:

    cd ~/Downloads
echo '7edc7987d2bf6a47db10381f5b39bb740ae331c2a2a5b9780b1e57898baf291f  Presspeech.zip' | shasum -a 256 -c -

    Continue only if it reports Presspeech.zip: OK. A checksum detects a damaged or different download; by itself, it does not establish who built or published the file.

    Verify the release attestation (optional)

    For an additional check, install GitHub CLI and verify both the immutable release and the exact archive you downloaded. Replace the tag below if you downloaded a different version:

    gh release verify v0.3.8 --repo rcourtman/presspeech
gh release verify-asset v0.3.8 ~/Downloads/Presspeech.zip --repo rcourtman/presspeech

    Both commands must succeed. This checks the release’s GitHub attestation and that the archive matches its attested asset; it does not prove the software is vulnerability-free or benign.

  3. Move it to Applications

    Unzip the archive, move Presspeech.app to Applications, then open it.

  4. Finish Setup Checklist

    The macOS 0.3.8 release starts its first ~500–600 MB model download on launch. In 0.3.9, a clean install must choose Download Model in Setup; choose Set Up Later to defer. Keep Presspeech open while the model prepares, then use Setup Checklist for the remaining checks.

Command line

Homebrew install and launch

brew install --cask rcourtman/presspeech/presspeech
open /Applications/Presspeech.app

Homebrew is the easiest path if you already use it or want command-line updates. On first launch, macOS shows its standard downloaded-app confirmation; choose Open after checking that it says Apple found no malicious software. The Presspeech icon then appears in the menu bar. The macOS 0.3.8 release starts its first ~500–600 MB model download on launch. In 0.3.9, a clean install must choose Download Model in Setup; choose Set Up Later to defer. Existing installs and cached models load automatically. If setup is not complete, Presspeech opens Setup Checklist; you can reopen it from the menu at any time.

To deliberately free menu-bar space, choose Settings → Behavior → Show Presspeech in Menu Bar. Presspeech enables its Dock icon if needed, and the Dock menu can restore the item. If a crowded or notched menu bar temporarily omits the item, open Presspeech.app again from Applications, Finder, or Spotlight. The already-running app opens Setup Checklist; enable Show in Dock there for a persistent alternative. Right-click its Dock icon to reach dictation controls, Settings, and Support.

Existing installations

Upgrade to the current Presspeech identity

Presspeech migrates preferences, hotkey choices, local dictionary rules, correction-sync paths, and recovery state automatically. macOS privacy grants cannot move between app identities, so grant Microphone, Accessibility (shown as Device Control and Data Access on macOS 27 and later), and Input Monitoring once when Setup Checklist opens.

Homebrew

Run brew update && brew upgrade --cask rcourtman/presspeech/presspeech. The fully qualified command trusts only this cask under Homebrew's tap-trust model. Launch Presspeech, accept the standard macOS downloaded-app confirmation, then finish the three permission rows in Setup Checklist.

Direct download

Quit the installed copy, replace it with the current Presspeech.app, and launch it once. Saved app settings migrate automatically; finish the fresh macOS permission grants in Setup Checklist.

Three grants

Permissions

Presspeech needs Microphone, Accessibility (shown as Device Control and Data Access on macOS 27 and later), and Input Monitoring. Setup Checklist shows each grant, explains why it is needed, and opens the relevant macOS prompt or Settings pane. macOS's Input Monitoring grant can expose typed keys; Presspeech's listener requests keyboard events only for the configured hotkey and Escape to cancel active dictation, passes other keys through without saving, logging, or sending their values, and does not inspect mouse or trackpad events. Review Apple's Input Monitoring guidance before deciding.

Review the scope before granting Accessibility. Apple describes this as access to control your Mac and advises granting it only to apps you trust; it may also expose contacts, calendar, and other information. Presspeech uses the grant to check the focused destination and send the paste shortcut. The system permission is broader than that use. If you leave it off, Presspeech cannot use its normal verified paste path. Read Apple’s accessibility-permission guidance before deciding.

These are local macOS privacy grants, not an account permission model. Presspeech has no cloud transcription endpoint or Presspeech-authored telemetry SDK, and no camera, contacts, calendar, location, file-provider, JIT, or unsigned-executable-memory entitlement. See the network-call inventory for bundled-library behavior by published version.

macOS permissions required by Presspeech
Permission Why it is needed
Microphone Record audio only while dictation is active; speech is transcribed locally on your Mac.
Accessibility (Device Control and Data Access on macOS 27+) Paste the transcript at the current cursor location with a synthetic ⌘ V event.
Input Monitoring Detect the configured hotkey and Escape to cancel an active recording. Apple's broad system grant can expose typed keys; Presspeech requests keyboard events only, does not inspect mouse or trackpad events, and passes other keys through without saving, logging, or sending their values.

Use the context-specific Continue, Open Settings, or Try Again actions in Setup Checklist. The main menu also shows clickable permission rows while anything is missing, so setup can continue even after the checklist window is closed.

From zero to dictation

Step-by-step

  1. Confirm the hardware

    Run uname -m. It must print arm64.

  2. Confirm macOS version

    Run sw_vers -productVersion. It should report 14 or later.

  3. Choose an install path

    Download Presspeech.zip, or run brew install --cask rcourtman/presspeech/presspeech.

  4. Launch the app

    open /Applications/Presspeech.app. The macOS 0.3.8 release starts its first ~500–600 MB model download on launch. In 0.3.9, a clean install must choose Download Model in Setup; choose Set Up Later to defer. Upgrades and cached models load automatically.

  5. Finish Setup Checklist

    Open the Presspeech menu and choose Setup Checklist…. Use it to finish the speech model, permissions, and hotkey check.

  6. Hold Right Option, speak, release

    Presspeech transcribes locally, then normally pastes into the window where you started. If it cannot verify that destination, it keeps the transcript on the clipboard and asks you to paste manually.

Maintenance

Update and uninstall

brew upgrade --cask rcourtman/presspeech/presspeech
brew uninstall --zap --cask rcourtman/presspeech/presspeech

The in-app update menu also appears when Presspeech finds a newer GitHub release. The menu only notifies; installation starts only after you choose Update Now.

Support

Get useful help without sharing your words

First check the FAQ and troubleshooting guide. Support → Copy Diagnostics copies a privacy-safe summary locally; it does not send or submit it. Support → Report a Problem… and Suggest an Improvement… open the repository's support guide, not an issue form. The summary includes app, system, permission, model, microphone availability, settings, and update state without transcript text, correction contents, exact microphone names, raw error details, or raw log lines. Review the separate local log before choosing to share any excerpt. Follow the guide for the current public-reporting status and privacy-safe draft steps. In macOS 0.3.8 and later, Support → Test App Compatibility… opens the repeated target-app protocol directly.

Feedback availability checked 23 September 2026: GitHub currently restricts creating new issues in this repository, so a new public report cannot be submitted there. Check for a matching existing issue and whether comments are available. Otherwise keep the privacy-safe draft local and retry when issue creation is available; do not post private data elsewhere as a workaround.

GitHub issues are public. Do not add dictated text, audio, dictionary or shortcut contents, credentials, or other private data. Use the private vulnerability-reporting form for a security issue.
