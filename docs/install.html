Install

Install Presspeech on macOS

Use the direct notarised download for the shortest path, or Homebrew if you want command-line install and updates. Setup Checklist then walks you through the local speech model, macOS permissions, and hotkey check.

Current published macOS release: 0.3.12. Install metadata updated 23 November 2026.

Download macOS 0.3.12 (.zip) First dictation guide Install with an assistant View latest release
$ brew install --cask rcourtman/presspeech/presspeech

Model download and privacy (macOS 0.3.12): Clean installs ask in Setup before downloading the ~500-600 MB local speech model (choose Download Model or Set Up Later), while existing installs with a missing model may download on launch. Presspeech strips inherited Hugging Face account tokens and rejects malformed https_proxy or http_proxy URLs before model loading. Valid proxy settings still route model requests, and dictation audio and transcripts are never sent. Review the version-specific network inventory or switch to the Windows install guide if you are on a PC.

Historical notice for macOS 0.3.8

macOS 0.3.8 started a missing-model download on launch without a Setup deferral choice, could attach an inherited Hugging Face token, and could log a malformed inherited lowercase https_proxy or http_proxy URL verbatim before ignoring it. If you are still on 0.3.8, leave it unopened until you upgrade to 0.3.9 or later, disable its login item in System Settings → General → Login Items & Extensions, and deselect Reopen windows when logging back in if waiting. Already ran macOS 0.3.8? Read the follow-up guidance.

Before you start

Requirements

Apple SiliconM1 or newer. Intel Macs are not supported.
macOS 14+Sonoma or later.
Direct or HomebrewDownload the signed zip manually, or use Homebrew for install and updates. Presspeech has no Homebrew runtime dependency after installation.
First model downloadInternet is required once for the ~500-600 MB local model. Clean installs wait until you choose Download Model in Setup, and a valid cached model loads offline.
Fast path

Direct download

  1. Download the app

    Download Presspeech 0.3.12 (.zip) from the current GitHub release.

  2. Optionally verify the archive

    In Downloads, verify the current archive against its published SHA-256:

    cd ~/Downloads
echo 'ed00b6494851446516e393456c980061174c7b53add62c029669a2ccdc575a17  Presspeech.zip' | shasum -a 256 -c -

    Continue only if it reports Presspeech.zip: OK. A checksum detects a damaged or different download, though by itself it does not establish who built the file.

    Verify the release attestation (optional)

    For an additional check, install GitHub CLI and verify both the immutable release and the exact archive you downloaded. Replace the tag below if you downloaded a different version:

    gh release verify v0.3.12 --repo rcourtman/presspeech &&
gh release verify-asset v0.3.12 ~/Downloads/Presspeech.zip --repo rcourtman/presspeech &&
echo 'Release and archive attestations verified'

    The success line appears only if both commands succeed. If either fails, stop and do not treat the archive as attested or launch it until you resolve the failure.

  3. Move it to Applications

    Unzip the archive and move Presspeech.app to Applications. If you chose to wait after reading the model-download privacy note, leave it unopened. Otherwise, open it to start Setup Checklist.

  4. Finish Setup Checklist

    Choose Download Model in Setup when ready (or Set Up Later to defer). Keep Presspeech open while the ~500-600 MB model prepares, then finish the permission and hotkey checks.

Command line

Homebrew install and launch

brew install --cask rcourtman/presspeech/presspeech

After reviewing the model-download privacy note, open the installed app:

open /Applications/Presspeech.app

Homebrew is the easiest path if you already use it or want command-line updates. On first launch, macOS shows its standard downloaded-app confirmation. Choose Open after checking that Apple found no malicious software, and the Presspeech icon appears in the menu bar. Clean installs wait for Download Model in Setup Checklist, while existing installs with a missing model may download on launch.

To free menu-bar space, choose Settings → Behavior → Show Presspeech in Menu Bar. Presspeech enables its Dock icon if needed so you can reopen controls. If a crowded or notched menu bar hides the icon, open Presspeech.app again from Applications, Finder, or Spotlight to show Setup Checklist and enable Show in Dock.

Existing installations

Upgrade an existing install

Presspeech migrates preferences, hotkey choices, local dictionary rules, correction-sync paths, and recovery state automatically. A valid cached model loads without another download. If an upgrade changes the app identity, macOS privacy grants cannot move with it, so review Microphone, Accessibility (Device Control and Data Access on macOS 27 and later), and Input Monitoring in Setup Checklist.

Homebrew

Run brew update && brew upgrade --cask rcourtman/presspeech/presspeech. Open Presspeech after upgrading, accept the standard macOS confirmation if shown, and finish any permission rows in Setup Checklist.

Direct download

Quit the running copy and replace Presspeech.app in Applications with the new build. Open it once and finish any permission rows still needed in Setup Checklist.

Three grants

Permissions

Presspeech needs Microphone, Accessibility (shown as Device Control and Data Access on macOS 27 and later), and Input Monitoring. Setup Checklist shows each grant, explains why it is needed, and opens the relevant macOS prompt or Settings pane. Because macOS Input Monitoring can expose typed keys, Presspeech requests keyboard events only for the configured hotkey and Escape to cancel dictation, does not inspect mouse or trackpad events, and passes other keys through without saving, logging, or sending them. Review Apple's Input Monitoring guidance before deciding.

Review the scope before granting Accessibility. Apple describes this as access to control your Mac and advises granting it only to apps you trust. Presspeech uses it to check the focused window and send the paste shortcut, though the system permission is broader than that use. Without it, Presspeech cannot use its normal verified paste path. Read Apple’s accessibility-permission guidance before deciding.

These are local macOS privacy grants, not an account permission model. Presspeech has no cloud transcription endpoint or Presspeech-authored analytics SDK, and no camera, contacts, calendar, location, file-provider, JIT, or unsigned-executable-memory entitlement. See the network-call inventory for full version details.

Permission Why it is needed

Setup Checklist labels a first microphone prompt Continue and an earlier denial Open Settings, and checks both focused-window access and keyboard-event posting before reporting Accessibility granted. The menu bar also shows clickable permission rows while anything is missing.

From zero to dictation

Step-by-step

  1. Confirm the hardware

    Run uname -m. It must print arm64.

  2. Confirm macOS version

    Run sw_vers -productVersion. It should report 14 or later.

  3. Choose an install path

    Download Presspeech.zip from the version-pinned release above, or run brew install --cask rcourtman/presspeech/presspeech.

  4. Open Presspeech

    Run open /Applications/Presspeech.app after reviewing the model-download privacy note. Clean installs ask before downloading the ~500-600 MB speech model.

  5. Finish Setup Checklist

    Open the Presspeech menu and choose Setup Checklist… to finish the speech model, permissions, and hotkey check.

  6. Hold Right Option, speak, release

    Presspeech transcribes locally and pastes into the window where you started. If it cannot verify that window, it keeps the transcript on the clipboard for manual paste. Keep the starting field and browser tab selected until insertion finishes.

For shell-capable assistants

Agent install prompt

Use this when asking a shell-capable assistant to install Presspeech on the target Mac.

Show the macOS install prompt 
Install Presspeech from https://github.com/rcourtman/presspeech on this Mac.

Before choosing an install or launch path, verify the published macOS version on https://github.com/rcourtman/presspeech/releases and the deployed https://rcourtman.github.io/presspeech/install.html#direct-download guide. Use the version-pinned download only when both identify the same available release; if they disagree or the release asset is unavailable, stop and wait. The source branch, release notes, and local site metadata can be ahead of the downloadable build. Do not infer publication from those files alone.

Before installing or launching, explain the model download. Presspeech downloads its local speech model (~500-600 MB) from Hugging Face; the public model needs no account token, and from 0.3.9 Presspeech removes inherited Hugging Face account tokens from its model requests. Model downloads do not include dictation audio or transcripts. Valid inherited lowercase `https_proxy` or `http_proxy` settings still route model requests: a TLS-inspecting proxy trusted by macOS can read them, while a tunnelling proxy cannot. If the user depends on a proxy whose trust is unclear, wait. From 0.3.9, Presspeech refuses to start if either setting is malformed, naming only the variable; the user corrects or removes it before relaunching. Downloading the ZIP or installing the app without opening it does not make the model request. On a clean install, Setup waits for Download Model or Set Up Later; an existing installation with a missing model may start a download on launch. Do not inspect or display token values or proxy values, change credential settings, share logs containing them, or launch without the user's informed choice. If the user chooses to wait, skip the `open` command below and leave the app unopened. See https://rcourtman.github.io/presspeech/privacy.html#network-calls.

Before downloading or installing, run these read-only compatibility checks:
  uname -m
  sw_vers -productVersion

Stop if the Mac is not Apple Silicon (arm64) or macOS is older than 14. Do not download, install, or launch Presspeech on an unsupported Mac.

Presspeech has two notarised install paths: a direct release zip and a Homebrew Cask. After the compatibility checks pass, check whether Homebrew is already available:
  command -v brew

If Homebrew is available and the user chooses it, install with:
  brew install --cask rcourtman/presspeech/presspeech

Otherwise offer the direct notarised zip using the current version-pinned download and verification steps at https://rcourtman.github.io/presspeech/install.html#direct-download. Do not install Homebrew just for Presspeech. After verification, unzip and move Presspeech.app to Applications, but do not follow the guide's launch instruction yet. Do not run the Homebrew command when Homebrew is unavailable.

Before launching, read the installed app's version without opening it:
  plutil -extract CFBundleShortVersionString raw -o - /Applications/Presspeech.app/Contents/Info.plist
If it does not match the published version and launch decision you reviewed, stop; do not launch a different installed build. If an older 0.3.8 build is present, also point the user to https://rcourtman.github.io/presspeech/privacy.html#macos-0-3-8-after-use. The installation method alone does not establish which version is present at that path.

Only after the user makes an informed choice to launch the verified published version:
  open /Applications/Presspeech.app

After launch, Download Model in Setup starts the speech-model download and Set Up Later defers it; a valid cached model loads without another download. Before asking the user to enable Input Monitoring, explain that macOS's grant can expose typed keys; Presspeech requests keyboard events only to detect the configured hotkey and Escape to cancel an active recording, passes other keys through without saving, logging, or sending their values, and does not inspect mouse or trackpad events. Offer Apple's guide at https://support.apple.com/guide/mac-help/mchl4cedafb6/mac. Use Setup Checklist to finish the model, permissions, and hotkey readiness. The default dictation key is Right Option. Focus on setup and the first in-app test; explain that the scratchpad can still use the system clipboard and use only harmless words. Do not ask the user to star, review, or otherwise endorse the project.

A successful Try Dictation scratchpad test proves only the in-app path, not automatic paste into another app. Do not use a production field, live chat, form that can submit, or command shell as a first target. If the user asks to try another app, follow https://rcourtman.github.io/presspeech/getting-started.html#first-app with harmless words in a blank, disposable field. Count an automatic-paste pass only when the complete text appears once with no recovery notice. On macOS, a copied notice is manual recovery, not a paste pass: inspect the intended field first, then verify the clipboard still holds the complete transcript before manual paste; a later copy may have replaced it. Do not retry blindly. Use https://rcourtman.github.io/presspeech/app-compatibility.html before relying on repeated delivery to a specific app.

Only if the user asks about a future build: check GitHub Releases and the deployed install guide before describing its controls as available. Source changes alone do not make a new download available.

Plain-text prompts for both macOS and Windows: install/agents.md.

Maintenance

Update and uninstall

brew upgrade --cask rcourtman/presspeech/presspeech
brew uninstall --zap --cask rcourtman/presspeech/presspeech

The in-app update menu also appears when Presspeech finds a newer immutable GitHub release. It only notifies you, and installation starts only after you choose Update Now.

Support

Get useful help without sharing your words

Start with the FAQ and troubleshooting guide. Support → Copy Diagnostics copies a privacy-safe summary locally without sending it, omitting transcript text, dictionary rules, exact microphone names, raw error details, and raw log lines. Support → Report a Problem… and Suggest an Improvement… open the repository's support guide, and Support → Test App Compatibility… opens the repeated target-app protocol.

GitHub issues are public. Never include dictated text, audio, dictionary or shortcut contents, credentials, or other private data. Use the private vulnerability-reporting form for a security issue.
