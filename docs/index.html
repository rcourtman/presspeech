macOS — released

The signed and notarised Swift menu-bar app runs multilingual Parakeet TDT v3 through CoreML on Apple Silicon. The 0.3.8 release starts its first 500–600 MB local model download on launch. In 0.3.9, a clean install must choose Download Model in Setup; close Setup to defer. Upgrades and cached models load automatically.

Before installing or launching macOS 0.3.8: model-download requests may include a Hugging Face token inherited by Presspeech. The public model needs no account token. If a token may be present in the environment that launches Presspeech—or you are unsure—wait until macOS 0.3.9 is published. Dictation audio and transcripts are not sent in these requests. Read the version-specific network inventory.

Windows — prerelease

The currently unsigned x64 installer is for evaluation on Windows 11 (recommended) or Windows 10 only while your specific edition remains supported or is enrolled in applicable Extended Security Updates. Microsoft ended general support for Windows 10 on 14 October 2025. Allow about 4.4 GB for the app, plus a first model download of about 2.5 GB with usable NVIDIA CUDA (multilingual Parakeet) or 141 MiB on CPU (English-only Whisper base.en). Upcoming 0.1.13 asks before downloading missing Parakeet files; published 0.1.12 does not. Other local models remain selectable.

Before installing or launching Windows 0.1.12: model downloads may send Hugging Face usage telemetry and include an already-configured or locally saved Hugging Face token. Custom download routing can change where the model request—and a token it carries—goes. If a Hugging Face token or custom download route is configured on this PC—or you are unsure—wait until Windows 0.1.13 is published. The public models need no account token; dictation audio and transcripts are not sent in model downloads. Read the Windows privacy decision and technical details and the version-specific network inventory.

Windows may block an unsigned installer, especially under Smart App Control or managed policy. Review the verification and security guidance before downloading; do not bypass a policy block.

The whole workflow

Hold. Speak. Release.

The video below shows the macOS build with its default Right Option hotkey. On Windows, use the same hold–speak–release gesture with Right Alt by default; if that key acts as AltGr for your keyboard layout, Setup lets you choose F8 or another available key. Press to toggle is also available in macOS Settings → Dictation → Trigger and in Windows Settings; the upcoming 0.1.13 build also exposes it in Setup.

Check an app before relying on automatic paste. Target apps, including browser editors, Electron/Chromium apps, terminal-based editors, and remote sessions, expose focus and paste behavior differently. Run the privacy-safe target-app check to separate automatic paste from clipboard recovery; it records outcomes, never your words.

macOS implementation

Built for one thing, not ten

Press and speak

Presspeech is a menu-bar utility, not a document manager. The default trigger is Right Option, with other hotkeys available from the menu.

Local speech recognition

Audio is captured in memory and transcribed locally. Presspeech pastes only after confirming the original window, or keeps the transcript available for deliberate manual paste; audio is then discarded and transcripts are not written to disk.

Native macOS stack

Swift, AVFoundation, CoreGraphics, AppKit, CoreML, and FluidAudio. No embedded browser runtime, interpreter, account, subscription, or cloud transcription endpoint.

Good fit

When Presspeech is the right pick

Use Presspeech when you want

Fast phrase-length dictation in everyday text fields, with a visible clipboard fallback when automatic delivery is unavailable; a local-only transcription model; and a workflow that does not keep a transcript library. The macOS app is released and notarised; the Windows app is available for people comfortable evaluating an unsigned prerelease.

Use something else when you need

Intel Mac or Windows on Arm support, macOS before 14 Sonoma, an installer accepted by managed Windows policies, batch file transcription, speaker labels, long-form transcript editing, cloud models, team features, or integrations with notes databases.
