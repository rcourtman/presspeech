How it works

Four steps from install to dictation

  1. Install the app Download the signed macOS release or verify the Windows prerelease installer.
  2. Approve model and permissions Clean installs ask before downloading the local speech model. Complete microphone and input permissions in Setup.
  3. Test in the scratchpad Open Try Dictation and speak a harmless practice sentence to confirm local transcription.
  4. Dictate anywhere Hold Right Option on Mac or Right Alt on Windows, speak, and release. Press to toggle is built in too.

Read the first-dictation guide for step-by-step setup and target-app verification.

macOS 0.3.12 · Released

Presspeech for macOS

Signed and notarised native Swift menu-bar app for Apple Silicon Macs on macOS 14 or later. Runs multilingual NVIDIA Parakeet TDT v3 on the Apple Neural Engine, with opt-in Parakeet Ultra in Settings. Clean installs ask before downloading the ~500-600 MB model.

Windows 0.1.14 · Prerelease

Presspeech for Windows

Unsigned x64 installer for Windows 11 (recommended) or Windows 10 editions still covered by security updates or Extended Security Updates. Allow about 4.4 GB for the app, plus ~2.5 GB for multilingual Parakeet on NVIDIA CUDA or ~141 MiB for English-only Whisper base.en on CPU. Setup asks before downloading and disables Hub telemetry and account tokens.

Using an older build (macOS 0.3.8 or Windows 0.1.12)?

Older builds started missing-model downloads on first launch without a Setup deferral prompt and could attach inherited Hugging Face tokens or Windows library telemetry. Review the macOS 0.3.8 follow-up guidance, macOS model-download privacy notes, and Windows model-download privacy notes before downloading again.

Built for one thing

Fast, deterministic, and local

Hold or press to toggle

Use Right Option on Mac or Right Alt on Windows, pick another hotkey in Settings, or switch to Press to toggle. Press Escape at any time to cancel a recording without touching your clipboard.

Safe paste and recovery

Presspeech checks that the original window is still focused before automatic paste. If focus changed or cannot be verified, it skips auto-paste and keeps the transcript available for manual recovery. Keep the starting field and tab selected until delivery finishes.

Voice shortcuts and corrections

Map spoken phrases to exact reusable text and local dictionary rules. Output stays deterministic with no generative rewriting model and no cloud call.

Spoken formatting

On macOS, opt in to deterministic English commands including “new paragraph”, “bullet point”, “comma”, and “open quote”. Selecting the French Language Hint switches formatting to French phrases.

Try Dictation scratchpad

Both apps include a built-in scratchpad to check your microphone, hotkey, and speech model with harmless words before dictating into another app.

Native footprint

Swift, AVFoundation, AppKit, CoreML, and FluidAudio on macOS, with a separate Python implementation on Windows. Audio stays in memory and is discarded after transcription, with no persistent transcript archive.

Good fit

When Presspeech is the right pick

Use Presspeech when you want

Fast phrase-length dictation in everyday text fields with a visible fallback when automatic paste is unsafe, a local-only speech model with no account or cloud path, and a lightweight tool that does not build a transcript library. The macOS build is signed and notarised, and the Windows build is available as an unsigned prerelease.

Use something else when you need

Intel Mac or Windows on Arm support, macOS older than 14 Sonoma, a code-signed Windows installer for managed policies, batch file or meeting transcription, speaker labels, AI rewriting, cloud models, or team sync. Compare Presspeech with other dictation apps.
