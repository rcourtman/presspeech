Private push-to-talk dictation for Mac and Windows.

Hold a key, speak, and release—or choose Press to toggle. Presspeech transcribes locally, with no account or cloud transcription. The published builds verify the original window, not a field or browser tab in the same window: keep the starting field and tab selected until delivery finishes. If Presspeech cannot safely verify the destination, a recovery notice means the transcript was copied at completion, but a later copy can replace it. Paste manually only if the clipboard still holds the transcript. Model downloads use the network; see the version-specific privacy inventory.

macOS 0.3.8: released, signed, and notarised for Apple Silicon on macOS 14+. Windows 0.1.12: an unsigned prerelease for x64 PCs; Windows 11 is recommended.

macOS — released

The signed and notarised Swift menu-bar app runs multilingual Parakeet TDT v3 through CoreML on Apple Silicon. The 0.3.8 release starts a missing 500–600 MB local model download on launch; a valid cached model loads without another download.

Before opening macOS 0.3.8: a missing-model request may include a Hugging Face token inherited by Presspeech; an inherited lowercase https_proxy can route it through a TLS-inspecting proxy trusted by macOS. If a token may be present—or you are unsure—wait until 0.3.9 is published. If the proxy's trust is unclear, do not launch 0.3.8 while it is in use. Downloading the ZIP does not start the request, so you can leave the app unopened. The public model needs no token; dictation audio and transcripts are not sent. Read the full macOS warning before deciding to launch.

Windows — prerelease

The currently unsigned x64 installer is for evaluation on Windows 11 (recommended) or Windows 10 only while your specific edition remains supported or is enrolled in applicable Extended Security Updates. Microsoft ended general support for Windows 10 on 14 October 2025. Allow about 4.4 GB for the app, plus a first model download of about 2.5 GB with usable NVIDIA CUDA (multilingual Parakeet) or 141 MiB on CPU (English-only Whisper base.en). Published 0.1.12 starts a missing selected model download on launch. Other local models remain selectable.

Before opening Windows 0.1.12: model downloads may send Hugging Face usage telemetry and an already-configured or locally saved token. Custom routing can change the request destination; a TLS-inspecting HTTPS proxy trusted by the client can read a token it receives. If you want to avoid possible telemetry, a token or custom route may be configured, or you are unsure, wait until 0.1.13 is published. If a TLS-inspecting proxy's trust is unclear, do not launch while it is in use. Downloading the installer and checksum does not start a model request; if you install but wait, leave Launch Presspeech unchecked. The public models need no token; dictation audio and transcripts are not sent. Read the full Windows warning before deciding to launch.

Already used Windows 0.1.12? If a model download ran with a token available and an inherited HF_ENDPOINT or staging setting may have sent it to a destination you do not trust—or an untrusted TLS-inspecting HTTPS proxy could read the request—treat the token as disclosed to that destination or proxy. A proxy that only tunnels HTTPS cannot read the token. Revoke the token and create a replacement at Hugging Face Access Tokens; do not include token values in logs or support requests.

Windows may block an unsigned installer, especially under Smart App Control or managed policy. Review the verification and security guidance before downloading; do not bypass a policy block.

The whole workflow

Hold. Speak. Release.

The video below shows the macOS build with its default Right Option hotkey. On Windows, use the same hold–speak–release gesture with Right Alt by default; if that key acts as AltGr for your keyboard layout, Setup lets you choose F8 or another available key. Press to toggle is available in macOS Settings → Dictation → Trigger and in Windows Settings.

Check an app before relying on automatic paste. Target apps, including browser editors, Electron/Chromium apps, terminal-based editors, and remote sessions, expose focus and paste behavior differently. On macOS 0.3.8, some Electron/Chromium apps can show the copied/manual-paste notice even when focus looks unchanged; that is recovery, not an automatic-paste pass. Run the privacy-safe target-app check to separate automatic paste from clipboard recovery; it records outcomes, never your words.

macOS implementation

Built for one thing, not ten

Press and speak

Presspeech is a menu-bar utility, not a document manager. The default trigger is Right Option, with other hotkeys available from the menu.

Local speech recognition

Audio is captured in memory and transcribed locally. Presspeech pastes only after confirming the original window. If verification fails, the published build copies the transcript at completion for manual recovery; check that the clipboard still holds it before pasting. Audio is then discarded and transcripts are not written to disk.

Native macOS stack

Swift, AVFoundation, CoreGraphics, AppKit, CoreML, and FluidAudio. No embedded browser runtime, interpreter, account, subscription, or cloud transcription endpoint.

Good fit

When Presspeech is the right pick

Use Presspeech when you want

Fast phrase-length dictation in everyday text fields, with a visible clipboard fallback when automatic delivery is unavailable; a local-only transcription model; and a workflow that does not keep a transcript library. The macOS app is released and notarised; the Windows app is available for people comfortable evaluating an unsigned prerelease.

Use something else when you need

Intel Mac or Windows on Arm support, macOS before 14 Sonoma, an installer accepted by managed Windows policies, batch file transcription, speaker labels, long-form transcript editing, cloud models, team features, or integrations with notes databases.
