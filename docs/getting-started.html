First dictation

From download to your first words

Install your platform build, finish Setup, and run a quick in-app test with harmless words before dictating into another app. Speech recognition runs on your device, while the initial speech-model download uses the network.

Before the first model download

Downloading the archive or installer makes no model request. On clean installs of current macOS 0.3.12 and Windows 0.1.14, Setup asks before downloading missing speech models and offers Set Up Later. Public model requests carry no inherited Hugging Face account token or bundled Hub telemetry, though configured proxy and CA settings still apply. Review your platform's macOS or Windows model-download note and the network-call inventory before downloading.

Using an older build (macOS 0.3.8 or Windows 0.1.12)?

macOS 0.3.8: Started missing-model downloads on launch without Setup deferral, could attach an inherited Hugging Face token, and could log malformed proxy URLs. Upgrade to 0.3.9 or later and review macOS 0.3.8 follow-up guidance.

Windows 0.1.12: Started missing-model downloads automatically, ran an automatic microphone check in Setup, and left bundled Hub telemetry and implicit authentication enabled. Upgrade to 0.1.13 or later and review Windows 0.1.12 follow-up guidance.

Your next step

Start from where you are

These checkpoints describe current macOS 0.3.12 and Windows 0.1.14 builds.

  1. Need to install Choose the macOS release or Windows prerelease guide. Downloading alone starts no model request.
  2. Installed, not Ready Finish Setup and let the local speech model reach Ready before testing the hotkey.
  3. Ready, not tested Use Try Dictation with harmless words and confirm the complete sentence appears.
  4. In-app test passed Try a blank TextEdit or Notepad field. Count automatic paste only when complete text lands once with no recovery notice.

If a step fails, stop there and match the status message in the troubleshooting guide.

Need to install?

Check your computer, then install

macOS 0.3.12

Requires Apple Silicon and macOS 14 or later. Signed and notarised. Clean installs ask before downloading the ~500-600 MB local model, and a valid cached model loads offline.

Install the macOS release

Windows 0.1.14 prerelease

Requires 64-bit x64 Windows 11 (recommended) or a supported Windows 10 edition with Extended Security Updates (general Windows 10 support ended 14 October 2025). Allow ~4.4 GB for the app, plus ~2.5 GB for multilingual Parakeet on NVIDIA CUDA or ~141 MiB for English-only Whisper base.en on CPU. Unsigned installer: verify SHA-256 first, and do not try to circumvent Smart App Control or managed policy.

Not supported: Intel Macs and Windows on Arm.

After launch

Finish setup before trying the hotkey

On macOS

  1. Prepare the speech model

    On a clean install, choose Download Model in Setup (or Set Up Later to defer). Wait until the model reports Ready.

  2. Grant the three permissions

    Approve Microphone, Accessibility (Device Control and Data Access on macOS 27 and later), and Input Monitoring. Accessibility is a broad system grant used to verify the focused window and paste. Input Monitoring can expose typed keys across apps, though Presspeech requests keyboard events only for the configured hotkey and Escape and passes other keys through without saving, logging, or sending them. See Apple's Input Monitoring guidance and the permission table.

  3. Confirm the hotkey

    Hold and release Right Option (or choose another key in Settings). Setup marks this Done after a real hotkey event.

On Windows 0.1.14

  1. Prepare the model or defer

    Choose the offered download or Set Up Later. A complete cached model loads without a network request. Wait for Ready before testing dictation.

  2. Check the microphone explicitly

    Choose Check Microphone for a brief local level check. Changing the selected input alone does not start capture, and samples are discarded in memory.

  3. Choose style, hotkey, and startup

    Choose Hold to talk or Press to toggle in Setup. Right Alt is the default, or pick F8 if it acts as AltGr. Start Presspeech with Windows is off for new profiles, while saved choices are kept. See the Windows first-launch steps.

Safe practice

Try your first dictation in Presspeech

Speak a harmless practice sentence in the built-in scratchpad to confirm local transcription before dictating into another app.

Clipboard note: The scratchpad is an in-app test field, not an isolation boundary from the system clipboard. Manual copies and normal delivery still use the OS clipboard, where macOS Universal Clipboard, Windows Clipboard History, or third-party clipboard managers may observe copied text. Practice with non-sensitive test words and review the clipboard privacy boundary before sensitive dictation.

  1. Open Try Dictation

    On macOS, choose Support → Try Dictation…. On Windows, choose Try Dictation… from Setup or the tray menu.

  2. Click the text area

    Keep the scratchpad focused so Presspeech can verify the target.

  3. Start, speak, and stop

    Hold the configured key, speak a short sentence, and release, or switch to Press to toggle in Settings to tap once to start and again to stop. Audio is discarded after local processing.

Ready to use

Dictate into a familiar text field

Open a blank TextEdit document on macOS or Notepad on Windows, click inside, and dictate a harmless sentence without switching windows or tabs. Press Escape to cancel an active recording. In every new target app, start with a disposable field that cannot submit or execute text.

Complete sentence once, no notice

Automatic paste worked for this field. Test other apps separately before relying on them.

No text, recovery notice

Presspeech skipped auto-paste and kept the text for manual recovery. Inspect the field first and follow the recovery steps below.

Partial, duplicate, or uncertain

Stop and inspect the disposable field before retrying. Follow the macOS or Windows recovery steps.

Manual recovery steps: Check the intended field first in case text already arrived. On macOS, a copied notice means the transcript was copied at completion, though a later copy can replace it. If the clipboard changed and Recent Transcripts is enabled, use Copy Last Transcript. On Windows 0.1.13 and later, use the explicit Copy, Discard, or Leave Waiting actions in Delivery Recovery, and reopen elevated apps normally rather than elevating Presspeech.

Command shells can run pasted text. macOS Append newline, Windows newline, or spoken formatting can submit a command immediately. Dictate shell commands into Try Dictation or a plain-text editor, review the exact text, and paste deliberately. See Apple and Windows terminal guidance.

Before relying on a browser editor, Electron app, terminal, or remote session, run the eight-check privacy-safe target-app protocol to separate automatic paste from manual recovery without sharing your words.

If you get stuck

Reopen controls and get help

macOS menu-bar item is hidden

Right-click the Dock icon and choose Show Presspeech in Menu Bar, or open Presspeech.app again from Applications, Finder, or Spotlight to show Setup Checklist and enable Show in Dock.

Windows tray icon is hidden

Check the notification-area overflow, or launch Presspeech again from the Start Menu to bring its controls forward without starting a second dictation process.

For model, permission, audio, or hotkey issues, check the troubleshooting guide. Copy Diagnostics copies a privacy-safe summary locally without sending it. For reporting steps, see the support guide, and use the private security reporting route for vulnerabilities. Never share dictated text, audio, dictionary contents, or credentials in a public issue.
