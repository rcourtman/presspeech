Need to install?

Check the computer, then use its install guide

macOS 0.3.8

Requires Apple Silicon and macOS 14 or later. The release is notarised. The 0.3.8 build starts its first 500–600 MB local model download on launch. In 0.3.9, a clean install must choose Download Model in Setup; close Setup to defer. Upgrades and cached models load automatically. Speech recognition runs on your Mac.

Before installing or launching: macOS 0.3.8 model-download requests may include a Hugging Face token inherited by Presspeech, though the public model needs no account token. If one may be present in the environment that launches Presspeech—or you are unsure—wait until macOS 0.3.9 is published. Dictation audio and transcripts are not sent. See the version-specific network inventory.

Windows 0.1.12 prerelease

  1. Check this PC

    Requires x64; Windows 11 is recommended. Use Windows 10 only while your specific edition remains supported or is covered by Extended Security Updates; general support ended on 14 October 2025.

  2. Check language and download size

    Allow about 4.4 GB for the app plus a first model download: usable NVIDIA CUDA selects multilingual Parakeet (~2.5 GB); without usable CUDA, the CPU default is English-only Whisper base.en (~141 MiB). Published 0.1.12 starts its selected download on first launch; upcoming 0.1.13 asks before downloading missing Parakeet files and offers the smaller CPU model or deferral. See the full language and model guide.

  3. Verify before running

    The installer is unsigned. Follow the SHA-256 verification steps. After checking the source and hash, you may choose More info → Run anyway for a SmartScreen warning. If Smart App Control or managed policy blocks it, stop—do not try to circumvent the block.

Before installing or launching Windows 0.1.12: its model downloads may send Hugging Face usage telemetry and include an already-configured or locally saved Hugging Face token. Custom download routing can change where the model request—and a token it carries—goes. If a Hugging Face token or custom download route is configured on this PC—or you are unsure—wait until Windows 0.1.13 is published. The public models need no account token; dictation audio and transcripts are not sent in model downloads. See the Windows privacy decision and technical details and the version-specific network inventory.

Already used Windows 0.1.12? Check token safety

If a model download ran with a token available and an inherited HF_ENDPOINT or staging setting may have sent it to a destination you do not trust, treat the token as disclosed to that destination. Revoke the token and create a replacement at Hugging Face Access Tokens; do not include token values in logs or support requests.

After launch

Finish setup before trying the hotkey

On macOS

  1. Prepare the speech model

    Wait for the speech model to finish preparing. If Setup prompts you to download it, choose Download Model; close Setup to defer. Keep Presspeech open while it prepares, and reopen Setup Checklist from the menu-bar item if needed.

  2. Grant the three permissions

    Use its buttons for Microphone, Accessibility (called Device Control and Data Access on macOS 27 and later), and Input Monitoring. Accessibility is a broad system-control grant: Apple advises granting it only to apps you trust. Presspeech uses it to check the focused destination and send the paste shortcut; without it, the normal verified paste path is unavailable. See the permission scope and Apple’s guidance before deciding.

  3. Confirm the hotkey

    Hold and release the displayed key. The default is Right Option. If it does not respond or controls another feature, choose a different key in Settings. You can open Try Dictation once Presspeech is Ready, before this test succeeds, and use the menu's Start Dictation and Stop and Transcribe controls. The checklist says Done only after a real hotkey event.

On Windows

  1. Reach Ready

    Wait until local model preparation finishes and Try Dictation becomes available.

  2. Check the microphone

    Published 0.1.12 checks the selected microphone automatically at startup and when its selection changes; choose Check Again to repeat it. Upcoming 0.1.13 keeps the microphone closed until you choose Check Microphone. The check briefly opens the selected input to measure its level; samples stay in memory and are discarded, not saved, sent, or transcribed. Windows may show its microphone-use indicator while the input is open. Speak during the check; if no level appears, select or unmute the correct input and repeat that version's check.

  3. Choose the hotkey and finish

    The default is Right Alt. If it acts as AltGr, choose F8 or another available key. Review Start with Windows, then finish setup.

Safe practice

Try the first dictation in Presspeech

Use the built-in scratchpad to check the complete flow without sending text into another app.

  1. Open Try Dictation

    On macOS, choose Support → Try Dictation…. On Windows, choose Try Dictation… from setup or the notification-area menu.

  2. Put the cursor in its text area

    Leave that field focused so Presspeech can verify the delivery path.

  3. Choose how to start and stop

    Hold the displayed key, say a short sentence, then release. Or choose Press to toggle—under Settings → Dictation → Trigger on macOS, or in Windows Settings (also in Setup in the upcoming 0.1.13 build)—to press once to start and again to stop. On macOS you can also choose Start Dictation and Stop and Transcribe from the menu. Continue when your sentence appears. Audio is discarded after local processing; the scratchpad is not a saved history.

No recording cue? Recheck the hotkey and microphone in Setup Checklist on macOS or Settings on Windows. Do not retry while the model is still preparing.

Ready to use

Dictate into a familiar text field

Open a blank TextEdit document on macOS or Notepad on Windows, click in it, and repeat hold–speak–release without changing windows. Press Escape to cancel an active recording.

If Presspeech copies instead: it cannot verify the same destination. Paste the existing transcript into the intended field; do not dictate it again first. This safe fallback can occur in some Electron/Chromium apps on macOS 0.3.8 even when the window appears unchanged. On Windows, reopen an administrator-level target normally rather than elevating Presspeech.

Command shells can run pasted text. Append newline, Windows newline, or spoken formatting can submit text. Dictate commands into Try Dictation or a text editor, review the exact text, then paste and run deliberately. See Apple and Windows terminal guidance.

Clipboard privacy: operating-system services or third-party clipboard managers can retain or sync copied text. Review the clipboard privacy boundary before dictating sensitive text.

Before relying on a browser editor, Electron app, terminal, or remote session, run the privacy-safe target-app check. It tests automatic paste and clipboard recovery without publishing your words.

If you get stuck

Reopen the controls

macOS item is hidden

Open Presspeech.app again from Applications, Finder, or Spotlight. The running app opens Setup Checklist instead of starting another copy. Enable Show in Dock there if you need a persistent alternative.

Windows icon is hidden

Check the notification-area overflow first. You can also launch Presspeech again from the Start Menu to restore its window or controls without starting a second dictation process.

For model, permission, audio, or hotkey recovery, use the troubleshooting guide. If the problem remains, Copy Diagnostics copies a privacy-safe summary but does not send it; review it and keep it private until there is a usable report route. Never post dictated text, audio, references, or dictionary contents to a public issue.

Public feedback is restricted (checked 23 September 2026). GitHub currently blocks creating new issues in this repository, so the in-app report actions and issue forms may not accept a submission. Check the existing issues for a relevant thread and whether comments are available. If there is no usable route, keep your report draft private and retry later; do not post private data elsewhere as a workaround. For a security concern, follow the private reporting instructions.

What to save in a private report draft

Keep only details useful for reproduction; this draft is not sent or monitored. Record the Presspeech and operating-system versions, affected stage, expected and observed result, smallest safe reproduction steps or frequency, generic target-app context if relevant, recovery tried and whether it worked, and attempt/failure counts. For text delivery, use harmless test text and record only whether complete text was recovered—never save or share the phrase itself. Keep diagnostics private until reviewed; do not include audio, transcripts, raw logs, credentials, private paths, or identifying names.
