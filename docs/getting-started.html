Need to install?

Check the computer, then use its install guide

macOS 0.3.8

Requires Apple Silicon and macOS 14 or later. The release is notarised; first launch needs an internet connection to download about 500–600 MB of local model files. Afterward, speech recognition runs on your Mac.

Install the macOS release

Windows 0.1.12 prerelease

  1. Check your PC

    Requires an x64 PC; Windows 11 is recommended. Microsoft ended general support for Windows 10 on 14 October 2025, so use Windows 10 only while your specific edition remains supported or is enrolled in applicable Extended Security Updates.

  2. Check language and download size

    Plan about 4.4 GB for the installed app, plus its first model download: usable NVIDIA CUDA selects multilingual Parakeet (~2.5 GB); without usable CUDA, the CPU default is English-only Whisper base.en (~141 MiB). Other local models remain selectable in Settings.

  3. Verify before running

    The installer is unsigned; verify its published SHA-256. After verification, SmartScreen may offer More info → Run anyway. If Smart App Control or managed policy blocks it, stop—do not try to circumvent the block. Follow the Windows verification steps.

Check requirements and install the Windows prerelease

Not supported: Intel Macs and Windows on Arm. For Windows 10, follow the support qualification above; see the Windows install guide before downloading.

After launch

Finish setup before trying the hotkey

On macOS

  1. Reach Ready

    Keep Presspeech open while the model prepares. Setup Checklist opens automatically; reopen it from the menu-bar item if needed.

  2. Grant the three permissions

    Use its buttons for Microphone, Accessibility (called Device Control and Data Access on macOS 27 and later), and Input Monitoring. Accessibility is a broad system-control grant: Apple advises granting it only to apps you trust. Presspeech uses it to check the focused destination and send the paste shortcut; without it, the normal verified paste path is unavailable. See the permission scope and Apple’s guidance before deciding.

  3. Confirm the hotkey

    Hold and release the displayed key. The default is Right Option. If it does not respond or controls another feature, choose a different key in Settings. Continue when the checklist says Done.

On Windows

  1. Reach Ready

    Wait until local model preparation finishes and Try Dictation becomes available.

  2. Check the microphone

    Speak during the input check. If no level appears, select or unmute the correct input, then choose Check Again.

  3. Choose the hotkey and finish

    The default is Right Alt. If it acts as AltGr, choose F8 or another available key. Review Start with Windows, then finish setup.

Safe practice

Try the first dictation in Presspeech

Use the built-in scratchpad to check the complete flow without sending text into another app.

  1. Open Try Dictation

    On macOS, choose Support → Try Dictation…. On Windows, choose Try Dictation… from setup or the notification-area menu.

  2. Put the cursor in its text area

    Leave that field focused so Presspeech can verify the delivery path.

  3. Hold, speak, release

    Use the displayed key, say a short sentence, then release. In toggle mode, press once to start and again to stop. Continue when your sentence appears. Audio is discarded after local processing; the scratchpad is not a saved history.

No recording cue? Recheck the hotkey and microphone in Setup Checklist on macOS or Settings on Windows. Do not retry while the model is still preparing.

Ready to use

Dictate into a familiar text field

Open a blank TextEdit document on macOS or Notepad on Windows, click in it, and repeat hold–speak–release without changing windows. Press Escape to cancel an active recording.

If Presspeech copies instead: it cannot verify the same destination. Return to the intended field and paste the existing transcript manually. On Windows, reopen an administrator-level target normally rather than elevating Presspeech.

Command shells can run pasted text. Append newline, Windows newline, or spoken formatting can submit text. Dictate commands into Try Dictation or a text editor, review the exact text, then paste and run deliberately. See Apple and Windows terminal guidance.

Clipboard privacy: operating-system services or third-party clipboard managers can retain or sync copied text. Review the clipboard privacy boundary before dictating sensitive text.

Before relying on a browser editor, Electron app, terminal, or remote session, run the privacy-safe target-app check. It tests automatic paste and clipboard recovery without publishing your words.

If you get stuck

Reopen the controls

macOS item is hidden

Open Presspeech.app again from Applications, Finder, or Spotlight. The running app opens Setup Checklist instead of starting another copy. Enable Show in Dock there if you need a persistent alternative.

Windows icon is hidden

Check the notification-area overflow first. You can also launch Presspeech again from the Start Menu to restore its window or controls without starting a second dictation process.

For model, permission, audio, or hotkey recovery, use the troubleshooting guide. If the problem remains, create a privacy-safe report with Copy Diagnostics, then choose Report a Problem… in the app or use the bug report form. For a recurring unmet need, choose Suggest an Improvement… or use the feature request form; describe the problem and a measurable result. Never post dictated text, audio, references, or dictionary contents to a public issue.

Feedback availability checked 23 September 2026: GitHub reports that issue creation is restricted for this repository, so the report forms may not accept a new submission. Check for a matching issue and whether comments are available; if there is no usable route, keep the privacy-safe report locally and retry later. Do not post private data elsewhere as a workaround.
