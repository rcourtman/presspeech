Fix a Presspeech problem

Choose your platform, then start with the symptom you can see. These steps use Presspeech's built-in setup and diagnostics controls before asking you to reset anything.

Fix a macOS problem Fix a Windows problem Report a problem safely
Start here

Check the visible state first

  1. Reopen Presspeech's controls

    On macOS, open Presspeech.app again from Applications, Finder, or Spotlight. On Windows, launch Presspeech again from the Start Menu. The running app restores its setup or settings window instead of starting a second dictation process.

  2. Read the model, microphone, and permission status

    Open Setup Checklist on macOS or Setup on Windows. Wait for the speech model to report ready, then use the built-in microphone and hotkey checks.

  3. Test inside Presspeech

    Choose Try Dictation. If the private scratchpad works, the model, microphone, and hotkey path are ready; continue with the paste and focus steps for your platform.

Model retries and update checks use the documented network connections, but dictation audio is not uploaded. See the privacy page for the complete network surface.

macOS

Recover the released Mac app

The menu bar item is missing

macOS can hide third-party status items when a crowded or notched menu bar runs out of space. Open /Applications/Presspeech.app again; the existing process opens Setup Checklist. Enable Show in Dock there for a persistent alternative. Right-click the Dock icon for dictation controls, Settings, Support, and Quit.

A permission is missing or will not appear

Open Support → Setup Checklist… and choose the affected Microphone, Accessibility, or Input Monitoring row. If the grant still does not appear, quit and reopen the copy in Applications, return to Setup Checklist, and choose Try Again. Presspeech then resets only that stuck permission entry and asks macOS again.

The speech model fails to load

Check the connection and retry first. If Presspeech reports an incomplete or corrupt cache, choose Support → Reset Speech Model Cache…. This deletes only the local model cache, then downloads and verifies a fresh copy; it does not remove settings or dictionary rules.

The hotkey does nothing

Confirm Settings → Hotkey shows the intended key and that Input Monitoring is granted in Setup Checklist. Use Settings → Hotkey → Reset Hotkey to Default to test Right Option. If a different app reserves that key, record another supported right-side modifier or F-key.

Try Dictation works, but text is not inserted

Confirm Accessibility is granted, click the destination text field, then hold the hotkey without changing apps until transcription finishes. Presspeech protects the app that had focus when recording began; if focus changes, it leaves the text on the clipboard instead of pasting into the wrong window. Paste manually once you have confirmed the intended destination.

System audio stays muted

Unmute the Mac in Control Center or Sound settings, then reopen Presspeech. The app uses a local watchdog and recovery marker to restore audio after an interrupted recording, and checks that marker again at launch. If it happens again, copy diagnostics before quitting.

Presspeech reports an unexpected exit

The notice means a local marker remained after the previous process ended; nothing was sent anywhere. Choose Copy Diagnostics or Open Log from the notice if you want to report what happened.

Windows

Recover the Windows prerelease

The notification icon is missing

Select the up-arrow at the right of the taskbar to check the notification-area overflow. You can also launch Presspeech again from the Start Menu. The existing process restores its open window, or opens Setup before first-run completion and Settings afterward.

The model is still preparing or failed

Keep Setup open and wait for the selected model to report ready. A hotkey press while it is preparing is intentionally ignored. If Setup reports a failure, choose Retry Speech Model. Check the connection and available disk space; on an NVIDIA system, also update the display driver or select a local Whisper model in Settings.

The microphone is silent or cannot open

In Setup, select the intended input, speak during the local level check, and choose Check Again. If it cannot open, use the buttons for Windows Microphone Privacy and Sound Input settings. Turn on Microphone access and Let desktop apps access your microphone, then confirm the input under Settings → System → Sound → Input. Windows does not show a separate Presspeech toggle for this desktop app.

The hotkey does nothing

Confirm the model says ready and check the selected key in Setup or Settings. If Right Alt types @, €, or accented letters, your keyboard uses it as AltGr; Presspeech deliberately leaves that chord alone. Choose F8 or another available modifier or F-key and retry in Try Dictation.

Try Dictation works, but text is not inserted

Click the destination text field before pressing the hotkey and keep that window focused until transcription finishes. If focus changes, Presspeech protects against sending private text to the wrong app: it leaves the transcript on the clipboard and shows a notification. Return to the intended field and paste manually.

Playback stays muted

Unmute the affected output from Windows Quick Settings or Settings → System → Sound, then reopen Presspeech. Recordings normally restore each playback device to its previous mute state, including when the configured maximum length stops a recording. Copy diagnostics if the state is not restored.

Start with Windows will not enable

Choose Open Startup Settings, find Presspeech under Settings → Apps → Startup, and review the system setting. Then return to Setup or Settings and retry Finish Setup or Save; Presspeech keeps the window open when registration fails rather than claiming success.

Still stuck?

Report the problem without reporting your words

  1. Copy the built-in diagnostics

    On macOS choose Support → Copy Diagnostics; on Windows choose Copy Diagnostics from the notification-area menu. The report includes bounded app, system, model, permission, microphone, settings, update, and log state.

  2. Describe what you expected and what happened

    Include short reproduction steps, the affected platform and version, whether the model reached ready, and whether Try Dictation worked. For Windows model failures, include CPU, GPU, and driver details when available.

  3. Use the focused public form

    Choose Report a Problem… in Presspeech or open the bug report form. Use the private vulnerability-reporting form instead for a security issue.

GitHub issues are public. Diagnostics omit transcript text, audio, and dictionary contents. Do not add dictated text, audio, references, dictionary or shortcut contents, credentials, or other private data yourself.
