Questions and answers

What is Presspeech?

Free MIT-licensed push-to-talk dictation with separate macOS and Windows apps. Hold a hotkey, speak, and release. Presspeech normally pastes into the window where the recording began; if it cannot verify that destination, it avoids automatic paste. The window check cannot always detect a move to another field or browser tab in the same window, so keep the starting field and tab selected until insertion or recovery. macOS and published Windows 0.1.12 use the clipboard for manual paste; upcoming Windows 0.1.13 waits for an explicit Delivery Recovery Copy or Discard when delivery is uncertain.

Do upgrades preserve settings and permissions?

macOS: Saved preferences and local dictionary rules migrate to the current Presspeech identity automatically. An upgrade that changes the bundle identity requires fresh Microphone, Accessibility (shown as Device Control and Data Access on macOS 27 and later), and Input Monitoring grants; otherwise, check Setup Checklist for any permission that still needs attention. Before reopening 0.3.8 after an upgrade, read the upgrade launch decision: a missing or invalid model cache can trigger a model request. Windows: Installing a newer prerelease over the existing app keeps settings in the current user profile.

Does audio leave my computer?

No. Neither app sends dictation audio to a transcription service. Model files download from Hugging Face during setup, but transcription runs locally and captured audio is discarded from memory after processing.

Which computers are supported?

macOS: Apple Silicon with macOS 14 Sonoma or later; Intel Macs are not supported. Windows: A 64-bit x64 PC with Windows 11 is recommended. Presspeech remains compatible with Windows 10 x64, but Microsoft has ended general Windows 10 support; use Extended Security Updates or an edition that remains supported. Windows on Arm is not supported.

How do I install it?

Before installing or launching macOS 0.3.8: its model-download requests may include a Hugging Face token inherited by Presspeech, although the public model needs no account token. FluidAudio also honors an inherited lowercase https_proxy; a TLS-inspecting proxy trusted by macOS can read a 0.3.8 token, while a tunnelling proxy cannot. If a token may be present in the environment that launches Presspeech, the trust of a TLS-inspecting proxy is unclear, or you are unsure, wait until macOS 0.3.9 is published. Dictation audio and transcripts are not sent. See the release-specific warning and version-specific network inventory.

Before installing or launching Windows 0.1.12: its model downloads may send Hugging Face usage telemetry and include an available token; custom routing can change where the token goes. A TLS-inspecting HTTPS proxy trusted by the client can read any 0.1.12 token it receives. Upcoming 0.1.13 removes account-token authentication but still honors proxy and CA settings. If a TLS-inspecting HTTPS proxy is in use and its trust is unclear, don't launch while it is in use. If you prefer to avoid this possible usage telemetry, are concerned that a token or custom route may be configured, or are unsure, wait until Windows 0.1.13 is published. Dictation audio and transcripts are not sent. See the release-specific warning and version-specific network inventory.

Safe stopping point: Downloading or installing either build without opening Presspeech does not start a model request. If you choose to wait, leave the app unopened. On Windows, the installer's final Launch Presspeech option starts checked; clear it before choosing Finish. If you already installed Presspeech, follow the existing-install wait steps to quit it and disable automatic launch. Check GitHub Releases in a browser for a newer build rather than opening the old app to check for updates. Neither newer build is published yet.

macOS: Review the current model-download privacy decision before following the direct-download or Homebrew steps in the macOS install guide. Windows: Follow the download and SHA-256 verification steps before running the currently unsigned installer.

What model does it use?

macOS: FluidAudio with multilingual Parakeet TDT v3 CoreML on the Apple Neural Engine. Windows: Fresh PCs with usable NVIDIA CUDA select multilingual Parakeet TDT v3; CPU-only PCs select the smaller English-only Whisper base.en model. Other local Windows models remain selectable.

Does the macOS Language Hint force a language?

No. Auto-detect (the default) leaves the decoder unrestricted. Selecting a language biases decoding toward its script and can reduce wrong-script output, but it does not translate speech or guarantee that the spoken language is identified correctly. Presspeech does not report a detected language.

Is it a file transcription app?

No. Presspeech is focused on live push-to-talk dictation into the app you are already using.

Does it keep a history?

macOS: The default is the last five transcripts in memory; the setting can keep none, one, or five, and everything clears on quit. Windows: There is no transcript history. Neither app writes transcript text to logs.

What permissions are required?

macOS: Microphone, Accessibility (shown as Device Control and Data Access on macOS 27 and later), and Input Monitoring. Setup Checklist tracks each grant. Windows: Turn on Microphone access, Let apps access your microphone, and Let desktop apps access your microphone. Standard Windows builds use these shared controls for desktop apps; some Insider Experimental builds add per-app controls and first-access prompts. If prompted, identify the requesting app before allowing it; an Unsigned label alone is not proof of Presspeech. Published 0.1.12 checks the microphone automatically during Setup, while upcoming 0.1.13 checks it only when you choose Check Microphone.

How do updates work?

Both apps can read public GitHub release metadata without sending a version, device, or user identifier. The macOS app checks every six hours. Windows checks on startup when automatic checks are enabled and 24 hours have passed since the recorded check. Published Windows 0.1.12 can repeat a failed check on each restart; upcoming 0.1.13 counts failed attempts toward that 24-hour interval. You can retry manually from the tray menu. Nothing downloads or installs without approval; Windows also verifies the installer size and SHA-256 before offering to run it.

Can I change the hotkey?

Yes. macOS: Choose a right-side modifier or F-key, or record a key with Command, Control or Option (plus optional Shift). The recorder previews the combination before saving it. Custom combinations take precedence over the same shortcut in other apps, and conflicts cannot all be detected. When Show in Dock is enabled, Presspeech's standard Command-comma Settings command takes precedence while Presspeech is active. Escape stays reserved for cancellation; the active layout's Command-V stays available for Paste recovery, even if a saved hotkey becomes that chord after an input-source change. Apple keyboards may require Fn for an F-key. Right Option is the default. Windows: Choose a left/right modifier or F8–F12; Right Alt is the default, but an AltGr keyboard layout should use F8 or another key.

Does it support voice shortcuts and formatting commands?

Yes. Both apps map spoken phrases to exact replacement text with deterministic local Dictionary & Shortcuts rules. On macOS, the optional spoken-formatting pass also handles commands such as “new paragraph”, “bullet point”, “comma”, and “open quote”. With the Language Hint set to French, it instead recognizes French line, paragraph, punctuation, quote, and parenthesis phrases such as “nouvelle ligne”, “nouveau paragraphe”, “virgule”, and “guillemet ouvrant”. Auto-detect and other language hints retain the English command set so short French words such as “point” are not rewritten accidentally.

Does Dictionary & Shortcuts teach the speech model?

No. Dictionary rules run after local transcription and replace the exact saved mishearing or spoken phrase. They do not bias the decoder or learn related spellings and grammatical forms, so add a separate rule for each distinct output that needs correction. Rules stay local; macOS can also export, import, or keep them in a user-chosen sync file.

How do I test my first dictation?

Before opening a build with a missing model, read the first-dictation guide's launch decision for your platform. After setup reports Ready, use Try Dictation with harmless words in its focused scratchpad. That in-app result does not prove paste works in another app. Next, try a blank TextEdit or Notepad field: count automatic paste only if complete text appears once with no recovery notice. A copied notice is manual recovery, not an automatic-paste pass; check the field and clipboard before pasting. Run the repeated target-app check in disposable fields before relying on another app.

Can I dictate into a command shell?

Treat Terminal, PowerShell, Command Prompt, and remote consoles as execution surfaces. The default paste suffix is a space; selecting Append newline on macOS or newline on Windows can submit a transcript before you inspect it. On macOS, spoken formatting can also insert line breaks. Use Try Dictation or a plain-text editor, review the exact command, then paste and run it deliberately. Terminal paste warnings vary by operating system, terminal, and settings; they are not a Presspeech safety boundary.

Why was the transcript not pasted?

Presspeech avoids automatic paste when it cannot verify the same destination it captured at the start. If the macOS 0.3.8 release says Copied — press ⌘V to paste (or Can’t verify window — use ⌘V for a missing starting window), it copied the transcript when dictation completed. Revised builds say ⌘V if clipboard unchanged. A later copy can replace that transcript, so use Copy Last Transcript if available rather than pasting newer clipboard content. Published Windows 0.1.12 says Transcript copied, not pasted; paste manually only if the clipboard still holds it. Upcoming Windows 0.1.13 may leave the previous clipboard item unchanged: check the intended field, then use Delivery Recovery → Copy for Manual Paste or Discard; do not blindly paste the previous clipboard item. Causes include a focus change, unavailable focused-window information, and—on Windows—a target running as administrator. The Mac and Windows recovery steps explain the platform details; the target-app check records repeatable results without publishing your text.

Can a clipboard service retain transcripts?

Yes. Presspeech does not sync transcripts itself, but delivery writes finished text to the system clipboard. macOS 0.3.8 can expose transcript entries to macOS Universal Clipboard. Builds containing local-only transcript clipboard writes use the current-device-only pasteboard option and standard transient, auto-generated, and concealed markers, preserving local Command-V while preventing Universal Clipboard transfer and asking cooperating managers not to archive or visibly expose the item. Apple’s Screen Sharing shared clipboard is a separate remote-transfer feature; local-only transcript writes have not been tested as a control for it. macOS Clipboard History in Spotlight on macOS 26 or later, arbitrary local clipboard readers, Windows clipboard services in published 0.1.12, or third-party software that ignores those advisory markers remain separate boundaries. Upcoming Windows 0.1.13 asks Windows to exclude Presspeech items from Clipboard History and Cloud Clipboard, but the current clipboard remains readable by local software. Review the clipboard privacy boundary before sensitive dictation.

Why does first launch take time?

Each app must download and prepare a local speech model before the first dictation. The macOS cache is about 500–600 MB. The 0.3.8 release starts its first download on launch; in 0.3.9, clean installs must choose Download Model in Setup or choose Set Up Later to defer. Existing installations and cached models load automatically. A fresh Windows install needs about 2.5 GB for CUDA Parakeet or about 141 MiB for CPU Whisper. Published Windows 0.1.12 starts its selected model download on first launch; upcoming 0.1.13 asks before downloading either missing first-run default and offers deferral on both paths, plus the CPU model on the Parakeet path. Later launches reuse the cache.

What is in diagnostics?

macOS Copy/Save Diagnostics and Windows Copy Diagnostics create privacy-safe reports with app, model, microphone availability, settings, and update state. They omit transcript text, audio, dictionary contents, exact microphone names, raw error details, and raw log lines; review the separate local log before sharing any part of it.

Which speech model should I use?

macOS: Use the built-in Parakeet TDT v3 model; there is no model switcher. Windows: Keep the automatically selected Parakeet CUDA or Whisper CPU default unless another selectable local model is a better fit for your language, accuracy, speed, or hardware.

How does it compare to other dictation apps?

The compare section has a side-by-side macOS table, a Windows decision guide, and focused pages for Handy and other adjacent tools. Short version: Presspeech is the small fixed-pipeline option; built-in Windows tools, Handy, and cloud services each make different privacy and workflow tradeoffs.
