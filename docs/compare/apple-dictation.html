Presspeech vs Apple Dictation

Apple Dictation is built into macOS. Presspeech is a focused third-party menu-bar app for local push-to-talk dictation with a documented engine, benchmark, and network surface.

Presspeech and Apple Dictation compared
Question Presspeech Apple Dictation
Install Direct notarised download or Homebrew Cask, three explicit privacy grants. Built into macOS, enabled from Keyboard settings.
Trigger model Hold-to-talk by default, toggle mode optional. Starts from the configured Dictation shortcut and stops manually or after inactivity.
Engine transparency Local Parakeet TDT v3 CoreML model through FluidAudio on the Apple Neural Engine. Apple documents where to check whether general text Dictation is processed on device for the current configuration.
Privacy posture No account, Presspeech-authored analytics, or persistent transcript history. Model downloads and optional update checks use the network; see the version-specific network inventory for published-build token and library-telemetry caveats. Governed by Apple's Dictation and privacy settings.
Best for Users who want a small auditable utility with a fixed local transcription path. Users who want the built-in system feature and do not want to install another app.

Sources: Presspeech source; Apple's Dictation guide, feature-availability list, and Siri and Dictation privacy page (checked 22 September 2026).
