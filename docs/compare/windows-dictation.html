Built-in, local, and cloud dictation are different choices

Windows includes both cloud-based Voice Typing and a separate offline Voice Access feature. Dedicated apps add push-to-talk workflows, local model choice, or AI rewriting. This table separates those tradeoffs; it does not rank accuracy or speed because there is no controlled head-to-head benchmark across these products.

Start with Voice Typing if zero installation matters and online processing is acceptable. Try Voice Access if you need offline dictation as part of full hands-free Windows control and it supports your language. Compare Presspeech and Handy when local push-to-talk and open source matter: Presspeech keeps a fixed per-platform path and no transcript library, while Handy prioritises model choice, one cross-platform app, and history. Aqua Voice is the different trade: cloud processing and a subscription in exchange for AI refinement and a shared commercial service across devices.
