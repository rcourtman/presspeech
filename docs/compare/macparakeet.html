Presspeech vs MacParakeet

Both are free, open-source Apple Silicon apps whose standard path runs Parakeet locally through FluidAudio and CoreML. MacParakeet is a broad voice workspace with model choice, file and meeting transcription, retained history, and optional AI. Presspeech stays focused on dictation, deterministic text handling, and explicit recovery when it cannot verify the original paste destination.

Presspeech and MacParakeet compared
Question Presspeech MacParakeet
Primary workflow Hold-to-talk or toggle, then normally paste only after confirming the same window is still focused. If that destination cannot be verified, keep the complete transcript on the clipboard for manual paste. Hold-to-talk or use a hands-free shortcut, then paste into the active app. An optional beta path can stream text at the caret; its broader app also handles files, media URLs, and meetings.
Speech engines and languages One fixed multilingual Parakeet TDT v3 path with auto-detection or a language/script-biased decoding hint for any of its 25 European languages; the hint is not a guaranteed language lock. Parakeet v3 is the standard-path default, with selectable Parakeet variants, Nemotron Beta, Cohere Transcribe, and WhisperKit. Its site documents 98 languages across engines and can select WhisperKit during setup for preferred CJK or Korean languages.
Text handling Deterministic dictionary corrections, exact shortcuts, filler removal, and opt-in spoken formatting. No generative rewriting. Deterministic cleanup, replacements, snippets, and voice-return triggers, plus optional formatting, summaries, chat, and selected-text transforms through local or configured cloud AI providers.
Stored history Audio is discarded after transcription. Optional recent transcripts remain in memory only and clear on quit; Presspeech has no persistent transcript archive. A local library stores completed work. Dictation history can retain raw and processed text, and meeting audio is kept by default unless the user changes its retention setting.
Privacy and network No cloud transcription or AI path, account, telemetry, analytics, or crash reporter. The complete network surface is documented and does not include a launch-time content feed. Speech recognition is local and needs no account. Optional cloud AI receives text, not captured audio. Analytics and crash reporting are opt-out; a Discover feed also loads at launch by default until Show Discover is disabled. Neither preference is a global network-off switch.
System and installation Apple Silicon and macOS 14+. Signed and notarised 8.4 MB zip or a project Homebrew tap; the fixed model cache is about 500–600 MB. Apple Silicon and macOS 14.2+. Signed and notarised DMG or the main Homebrew Cask. The standard first run downloads about 465 MB for Parakeet, with roughly 130 MB of speaker assets as needed; other engines require separate downloads.
Published evidence Publishes model-only release-to-transcript latency on fixed short clips, plus a separate target-app protocol for automatic paste and safe focus-change recovery. Publishes accuracy, throughput, and memory benchmarks across its local engines on LibriSpeech and FLEURS fixtures. These do not measure the same workload or boundary as Presspeech's latency results.
Platform and automation scope The released app is macOS-only; a separate x64 Windows build is available as an unsigned prerelease. No command-line automation surface. macOS-only. A bundled and separately packaged command-line tool can automate models, file transcription, history, meetings, and exports.
Price and license Free and MIT licensed. Free and GPL-3.0 licensed.

Choose MacParakeet if you want one local Mac workspace for dictation, files, media, meetings, broad-language model choice, persistent history, AI features, or command-line automation. Choose Presspeech if you want a smaller dictation-only app with no persistent transcript archive, telemetry, content feed, or AI-provider path, and with same-window delivery checks plus explicit manual recovery. Test either app in the exact target fields you rely on; no product's “any app” wording proves universal insertion behavior.

Sources: Presspeech source and platform documentation, Presspeech privacy and network documentation, Presspeech benchmarks, and its target-app protocol; the official MacParakeet site, release history, and source, privacy, feature, and benchmark documentation for stable version 0.8.7 (checked 22 September 2026).
