Presspeech vs Superwhisper

Both can transcribe on-device on Apple Silicon. Superwhisper is a configurable dictation workspace with model choice, optional AI post-processing, meeting and file tools, and Mac, Windows, iOS, and Android apps. Presspeech is a free single-purpose push-to-talk pipeline tuned for one thing — latency.

Presspeech and Superwhisper compared
Question Presspeech Superwhisper
Primary workflow Hold hotkey, speak, release; local model transcription is followed by deterministic text handling and normally a paste after confirming the same window is still focused, with manual clipboard recovery when needed. Record with a hotkey, then optional AI modes reshape the output (notes, messages, custom prompts) before insertion.
Engine path Local Parakeet TDT v3 CoreML model on the Apple Neural Engine, decoded in a single pass on key release. Choice of local Whisper models on the Free tier, local Parakeet and Cohere models on Pro, plus optional cloud voice models and local or cloud language models.
Privacy posture No cloud path exists: no account, no telemetry, transcript history in memory only. Voice transcription and optional text post-processing are configured independently; either stage can stay local or use a cloud provider.
Platforms Apple Silicon Macs, macOS 14 or later; a separate Windows preview is available. macOS 14+, Windows, iOS, and Android; model and acceleration support varies by device.
Price Free and MIT licensed. Free tier with all local Whisper models and up to two modes; Pro is $8.49/month, $84.99/year, or $249.99 once.
Configurability Deliberately minimal: hotkey, trigger style, language pinning, local text corrections. Extensive: modes, prompts, model management, vocabularies, and per-app behavior.

Choose Superwhisper if you want model choice, AI-shaped output, meetings, or desktop and mobile coverage, and the tiers fit your budget. Choose Presspeech if you want a free tool that does one job with a fixed engine, deterministic text handling, and no cloud path at all.

Sources: Presspeech source, Presspeech benchmarks; Superwhisper's platform and workflow overview, system requirements, voice-model catalog, data-flow guidance, and plans and pricing (checked 22 September 2026).
