Presspeech vs FluidVoice

Both are free local-first Mac dictation apps built around native speech engines. FluidVoice offers live preview, a broad model catalogue, and optional local or cloud AI enhancement. Presspeech uses one fixed local model path and deterministic text handling, with no AI rewriting, analytics, or persistent audio history.

Presspeech and FluidVoice compared
Question Presspeech FluidVoice
Primary workflow Hold-to-talk or toggle, then transcribe on release. Presspeech normally pastes only after confirming the same window is still focused, with manual clipboard recovery when that destination cannot be verified. Start from a global hotkey, see supported engines transcribe in a live preview, and insert text into the active field through macOS Accessibility APIs.
Speech engines One fixed path: multilingual Parakeet TDT v3 through FluidAudio and CoreML on the Apple Neural Engine. A selectable catalogue including Nemotron Speech 3.5, Parakeet Flash, Parakeet TDT v2/v3, Cohere Transcribe, Apple Speech, and Whisper-family models.
Text handling Deterministic dictionary corrections, exact voice shortcuts, filler removal, and opt-in spoken formatting. No AI rewriting. A custom dictionary and configurable spoken formatting, plus optional rewriting and formatting through local Fluid Intelligence or a configured cloud AI provider.
Privacy and network No cloud transcription or AI path, account, telemetry, analytics, or crash reporter. The documented network surface is model downloads, optional update checks, and user-triggered feedback and installation links. Speech models run locally, and cloud AI enhancement is opt-in. FluidVoice documents one anonymous daily activity signal uploaded in a weekly batch even when detailed analytics is disabled; it says voice, audio, transcripts, selected text, prompts, window titles, and clipboard content are not collected.
History Recent transcript history is held in memory only and clears on quit. Audio is discarded after transcription. Optional local audio history can retain recordings with storage-budget controls and ZIP export.
System and footprint Apple Silicon and macOS 14+. The release zip is 8.4 MB and the fixed speech model cache is about 500–600 MB. macOS 15+. Apple Silicon supports the full model catalogue; Intel Macs use Apple Speech or Whisper. The v1.6.9 DMG is 47 MB, speech models range from built-in to about 2.9 GB, and optional Fluid Intelligence needs about 3.5 GB.
Price and license Free and MIT licensed. The app is free and GPLv3 licensed. Fluid Intelligence is a separate, privately maintained local runtime; cloud AI providers require the user's own configuration.

Choose FluidVoice if live transcription, model switching, Intel Mac support, optional audio history, or local AI rewriting matters most. Choose Presspeech if you want macOS 14 support and a smaller fixed pipeline with deterministic output, explicit paste-destination recovery, no retained audio, and no analytics or cloud-AI path.

Sources: Presspeech source and platform documentation, Presspeech privacy and network documentation, Presspeech benchmarks, FluidVoice source and documentation, and its v1.6.9 release and release assets (checked 22 September 2026). No cross-product latency or accuracy winner is claimed because there is no controlled head-to-head benchmark.
