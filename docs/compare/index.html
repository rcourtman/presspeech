Every tool here wins somewhere. Pick the AI-formatting tools if you want your words reshaped, Apple Dictation if you want zero install, VoiceInk if you want one configurable local Mac app, or Handy if you want a larger cross-platform open-source community and model choice. Presspeech's case is narrow on purpose: a measured low-latency path from key release to pasted text, a small native macOS app, and no cloud transcription path to audit.

Presspeech's figures are measured on an M4 Mac mini and reproducible from the benchmark harness. Other tools' figures come from their official sites, docs, and release assets, checked 1 September 2026. “Not published” means we could not find an official number, nothing more. MacWhisper sits out this table because it is primarily a file-transcription app; it has its own page. Handy is the closest high-adoption open-source alternative and has its own page rather than making this Mac-focused table wider. Spotted an error? Open an issue and we will fix it.
