# Presspeech for Windows 0.1.14

> **Before launching Windows 0.1.14:** Setup asks before the first missing
> model download and offers deferral; a complete cached model loads without a
> request. Model downloads use the network. This release disables bundled Hub
> telemetry and account-token authentication, but configured proxy and CA
> settings still apply. Review their trust before choosing a download.
> Dictation audio and transcripts are not sent in model requests. Read the
> [Windows model-download privacy guide](https://rcourtman.github.io/presspeech/windows.html#model-download-privacy)
> before launching or clearing a working cache.

This prerelease fixes a toggle-mode modifier-hotkey paste race and refreshes
the hash-locked Windows runtime dependencies.

## Toggle-mode delivery

- When stopping a recording in **Press to toggle** mode with a modifier hotkey
  (such as Right Alt), wait up to 500 ms for that hotkey’s own side-specific
  modifier key to be released before running the held-modifier paste guard.
- Any unrelated held modifier or focus change still enters Delivery Recovery
  immediately without overwriting the prior clipboard item, and holding the
  stop modifier past the 500 ms bound preserves Delivery Recovery. Hold-to-talk
  behavior is unchanged.

## Runtime dependencies and packaging

- Refresh the hash-locked Windows release dependency graph (`huggingface-hub`
  2.4.0 with `httpx2` 2.16.2 and `httpcore2` 2.16.2, `transformers` 5.24.0,
  `onnxruntime` 1.32.0, `ctranslate2` 4.9.1, `pycaw` 20260927, `comtypes`
  1.5.0, `pyinstaller-hooks-contrib` 2026.10, and transitive updates) and
  bundle `httpx2` and `httpcore2` package metadata in the frozen PyInstaller
  build.
- Model-download privacy and proxy behavior remain unchanged on `httpx2`:
  Hub telemetry and implicit account-token authentication remain disabled before
  imports, the public Hub endpoint remains fixed, `hf-xet` (1.8.0) remains
  bypassed, and configured `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY`, `NO_PROXY`,
  `SSL_CERT_FILE`, and `SSL_CERT_DIR` settings (`trust_env=True`) still apply.

## Validation and remaining coverage

This remains an unsigned prerelease. Hosted qualification covers hash-locked
wheel verification, installer transaction and upgrade recovery, repeat
installation, installed CPU model loading and decoder warm-up, startup and
data preservation, and uninstall. Physical microphone/input, target-app
delivery, GPU, sleep/wake, and hardware power-loss testing remain deferred;
those paths are not represented as qualified. Audio retention is unchanged.

After installing this release, you can help verify automatic paste and safe
recovery in one target app by running the short, privacy-safe [compatibility
protocol](https://rcourtman.github.io/presspeech/app-compatibility.html).
Passing reports are useful too; share only aggregate outcomes from blank,
disposable fields, never dictated text or clipboard contents. Before sharing,
check the [support guide](https://github.com/rcourtman/presspeech/blob/main/SUPPORT.md)
for a current reporting route.
