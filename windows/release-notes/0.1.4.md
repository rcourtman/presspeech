Presspeech for Windows 0.1.4 hardens recording lifecycle recovery and the
user-approved update path.

### Fixed

- Recordings now stop automatically after two minutes if Windows misses a
  hotkey release, bounding in-memory audio and restoring muted playback.
- Recording startup, microphone callbacks, post-roll completion, and the new
  duration limit are scoped to the recording that created them. Delayed work
  from an older recording can no longer attach to or stop a newer one.
- Update API redirects are rejected. Installer and checksum redirects must
  remain HTTPS on approved GitHub release hosts at every hop.

Speech recognition remains entirely local. Update checks still send no app
version, device details, settings, transcripts, or usage identifiers. This
build is not yet code-signed, so Windows SmartScreen may show **Unknown
publisher**; choose **More info → Run anyway** after verifying the supplied
SHA-256 checksum.
