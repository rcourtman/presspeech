Presspeech for Windows 0.1.3 makes startup readiness truthful and prevents
dictation controls from activating before the local speech model is usable.

### Fixed

- Push-to-talk is now gated on the configured model being loaded and fully
  warmed.
- An early hotkey press keeps **Preparing speech model…** visible and does not
  open the microphone, play start/stop cues, mute playback, or show misleading
  **Listening… / Transcribing…** states.
- The scratchpad Dictate button follows the same readiness rule.
- A failed or explicitly unloaded model remains retryable, with only one load
  attempt queued at a time.

Speech recognition remains entirely local. This build is not yet code-signed,
so Windows SmartScreen may show **Unknown publisher**; choose **More info →
Run anyway** after verifying the supplied SHA-256 checksum.
