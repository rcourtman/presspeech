Presspeech for Windows 0.1.1 makes first launch and ongoing maintenance clearer
without changing the fast, local dictation path.

### What's new

- First-run readiness window showing model status, microphone selection,
  push-to-talk key, and Start with Windows
- Optional privacy-safe daily update checks plus a manual tray-menu check
- User-approved installer downloads verified against the GitHub asset size and
  published SHA-256 before Presspeech offers to run them
- Copy Diagnostics tray action with runtime and configuration metadata but no
  transcript, audio, or dictionary contents
- Atomic settings writes for safer background update checks and UI saves

### Privacy and signing

Speech recognition remains entirely local. Update checks send a fixed User-Agent
and ordinary HTTPS metadata only; no app version, device identifier, settings,
audio, transcript, or usage counts are attached.

This build is not yet code-signed. Windows SmartScreen may show **Unknown
publisher**; choose **More info → Run anyway** after verifying the SHA-256
checksum supplied with the installer.
