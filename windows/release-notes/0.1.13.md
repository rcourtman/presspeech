# Presspeech for Windows 0.1.13 (unreleased)

- Retain a finished dictation in memory when clipboard access fails, its original
  target cannot be used, a newer copy replaces it before paste, or keyboard
  delivery becomes uncertain. Recording waits until you review that text.
- Add explicit **Copy Undelivered Dictation** and **Discard Undelivered Dictation**
  tray actions. Reopening Presspeech shows controls and a recovery notice without
  silently overwriting the clipboard. Exit forgets retained text.
- Capture clipboard write receipts while Windows still excludes other writers,
  and recheck before sending the paste shortcut. Attempt key-up cleanup even
  when a key-down call fails after an uncertain side effect.

- Apply model-download privacy controls before dependencies load: explicitly
  decline account tokens, fix the public Hub endpoint, disable Hub telemetry
  and request debug logging, and replace Transformers' random session identifier
  with a fixed value. Require safetensors and reject remote model code.

Check the intended field before retrying an uncertain paste. Clipboard checks
cannot acknowledge consumption or eliminate the final check/input race. Retained
text stays in process memory only; explicit copies are subject to Windows
clipboard history and other clipboard services.
