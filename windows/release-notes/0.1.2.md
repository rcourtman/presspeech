Presspeech for Windows 0.1.2 fixes playback muting on PCs with more than one
active audio output.

### Fixed

- Dictation now mutes every active Windows playback endpoint, rather than only
  the default multimedia device. This covers audio routed separately to a
  headset, Realtek speakers, HDMI output, or another active endpoint.
- Every endpoint's original mute state is saved and restored independently.
- A failure on one endpoint no longer prevents other endpoints from being
  muted or safely restored, and the log records endpoint counts and failures.

Speech recognition remains entirely local. This build is not yet code-signed,
so Windows SmartScreen may show **Unknown publisher**; choose **More info →
Run anyway** after verifying the supplied SHA-256 checksum.
