Presspeech for Windows 0.1.10 makes update downloads respect the update
window's lifetime.

### Fixed

- Closing the update window now cancels an active installer download instead
  of allowing the multi-gigabyte transfer to continue invisibly in the
  background.
- Cancelled downloads remove their private partial file and never reach the
  install prompt.

The installer still receives the full update security checks: Presspeech
accepts only the exact versioned assets from a canonical Windows prerelease,
checks GitHub's published sizes and SHA-256 digests, verifies the checksum
asset, and locks and revalidates the installer immediately before process
creation.

Speech recognition remains entirely local. Update checks still send no app
version, device details, settings, transcripts, or usage identifiers. This
build is not yet code-signed, so Windows SmartScreen may show **Unknown
publisher**; choose **More info → Run anyway** after verifying the supplied
SHA-256 checksum.
