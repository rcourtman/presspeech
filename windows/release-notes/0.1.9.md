Presspeech for Windows 0.1.9 hardens the verified update path from GitHub
release selection through installer process creation.

### Fixed

- Presspeech now keeps both the verified installer and its containing directory
  locked until Windows creates the installer process. This closes the remaining
  parent-path replacement window after the final size and SHA-256 check.
- Update checks now request enough GitHub release metadata to keep Windows
  prereleases visible as macOS releases accumulate.

### Release integrity

- The updater accepts only canonical `windows-vX.Y.Z` prereleases with exactly
  the expected versioned installer and checksum assets, including GitHub's
  published sizes, SHA-256 digests, states, names, and canonical URLs.
- The release workflow verifies those same public asset properties against the
  locally built files before reporting a successful publication.

Speech recognition remains entirely local. Update checks still send no app
version, device details, settings, transcripts, or usage identifiers. This
build is not yet code-signed, so Windows SmartScreen may show **Unknown
publisher**; choose **More info → Run anyway** after verifying the supplied
SHA-256 checksum.
