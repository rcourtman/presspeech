> **Before opening this published prerelease:** A missing-model download
> starts on launch and may send Hugging Face usage telemetry or an available
> account token. Custom download routing can change where that request—and a
> token it carries—goes. A TLS-inspecting HTTPS proxy trusted by the client
> can read any 0.1.12 token it receives; do not launch while such a proxy is
> in use if its trust is unclear. The public models need no account token.
> If you prefer to avoid possible telemetry, a token or custom route may be
> configured, or you are unsure, wait until Windows 0.1.13 is published.
> Downloading the installer and checksum alone does not make a model request;
> if you install but choose to wait, leave **Launch Presspeech** unchecked.
> Dictation audio and transcripts are not sent in model downloads. Read the
> [Windows privacy decision and after-use guidance](https://rcourtman.github.io/presspeech/windows.html#model-download-privacy).

Presspeech for Windows 0.1.12 recovers from microphone hardware changes
without requiring an app restart and refreshes the pinned CUDA runtime.

### Audio-device recovery

- If a selected or automatic microphone disappears, Presspeech can safely
  refresh PortAudio's device table and retry discovery when the device is
  reconnected. A specifically selected device still fails safely rather than
  silently switching to a different microphone.
- Process-wide coordination prevents a device refresh from terminating
  PortAudio while a recording, microphone check, stream construction, or
  device query is active. Slow driver work does not hold the app state lock,
  and stale discovery from an earlier recording cannot overwrite a newer one.
- Native streams whose first close attempt fails remain protected and are
  retried before any later backend reset, avoiding unsafe recovery around a
  handle that the audio driver may still consider live.

### Release runtime

- The Windows CUDA package now pins Torch 2.14.0 with CUDA 12.6, and the
  resolved Python 3.12.10 release graph remains locked and reproducible.

### Installation and updates

- Uninstall now removes the current user's Presspeech startup entry, preventing
  Windows from trying to launch a removed executable at sign-in.
- Update checks accept only releases that GitHub marks immutable. Publication
  verifies the release attestation and both installer and checksum assets.
- Before publication, the hosted Windows runner checks the finished installer's
  install, packaged self-test, startup-entry cleanup, and uninstall behavior.

This remains a prerelease. The complete microphone, target-app, upgrade, and
assistive-technology qualification matrix is still required before stable promotion.

Speech recognition remains entirely local, and transcript and dictionary text
remain excluded from diagnostics. This build is not yet code-signed, so
Windows SmartScreen may show **Unknown publisher**; choose **More info → Run
anyway** only where local policy permits, after verifying the supplied SHA-256
checksum.
