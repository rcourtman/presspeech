Presspeech for Windows 0.1.7 hardens both in-app updates and the release
pipeline that produces them.

### Fixed

- Update downloads are now bounded by the installer size published by GitHub,
  and stop immediately if a response exceeds that size.
- Presspeech rechecks the approved installer's exact filename, size, and
  SHA-256 immediately before launching it. A file changed after download is
  rejected instead of executed.
- Downloads use an exclusively created random staging file, preventing a
  pre-existing link at the former predictable `.part` path from redirecting
  or truncating another file.

### Release integrity

- Windows releases are bound to the exact approved `main` commit and versioned
  tag before artifacts can be published or replaced.
- Frozen builds now run a model-free package smoke test before installer
  creation, catching missing lazy imports and native runtime modules.

Speech recognition remains entirely local. Update checks still send no app
version, device details, settings, transcripts, or usage identifiers. This
build is not yet code-signed, so Windows SmartScreen may show **Unknown
publisher**; choose **More info → Run anyway** after verifying the supplied
SHA-256 checksum.
