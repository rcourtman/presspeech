Presspeech for Windows 0.1.5 improves transcript cleanup and makes optional
GPU-idle model unloading reliable across repeated dictations.

### Fixed

- Filler removal now repairs punctuation and sentence capitalization after
  removing “um”, “uh”, and similar speech. It also preserves real words and
  compounds such as “well”, “err”, “uh-huh”, and “ohm”.
- Optional idle model unloading now stays on Presspeech’s permanent model
  worker and waits behind any queued transcription. Every transcription
  attempt refreshes the idle deadline, including empty or failed results, so a
  stale timer cannot unload the model immediately after it was used.

Speech recognition remains entirely local. Update checks still send no app
version, device details, settings, transcripts, or usage identifiers. This
build is not yet code-signed, so Windows SmartScreen may show **Unknown
publisher**; choose **More info → Run anyway** after verifying the supplied
SHA-256 checksum.
