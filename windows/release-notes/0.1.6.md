Presspeech for Windows 0.1.6 makes fresh model downloads reproducible and
keeps them tied to the version that passed Presspeech's native QA.

### Fixed

- Parakeet TDT v3 now loads an immutable Hugging Face snapshot instead of the
  model repository's mutable `main` branch. A fresh 0.1.6 install therefore
  receives the same model configuration and weights that passed the Windows
  CUDA/ASR gate.
- The pin is preserved through the normal FP16 load and both FP32 fallback
  paths. The retained Nemotron and Moonshine Transformers backends are pinned
  to reviewed snapshots as well.

This intentionally freezes the model revisions already exercised by
Presspeech; it does not change the speech engine or send any new network data.
Speech recognition remains entirely local. Update checks still send no app
version, device details, settings, transcripts, or usage identifiers. This
build is not yet code-signed, so Windows SmartScreen may show **Unknown
publisher**; choose **More info → Run anyway** after verifying the supplied
SHA-256 checksum.
