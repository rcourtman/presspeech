First packaged Windows release of Presspeech.

### What is included

- Self-contained Windows x64 installer: no Python or command-line setup required
- NVIDIA Parakeet TDT 0.6B v3 with CUDA acceleration and duration-aware decoding
- Whisper fallbacks, British spelling, local dictionary rules, audio cues, playback muting, and visual status indicator
- Right Alt hold-to-talk, configurable hotkeys, deterministic microphone selection, and Start with Windows support
- Local-only audio processing with no accounts, telemetry, or transcript logging

### Requirements and first launch

- Windows 10 or 11, x64
- A current NVIDIA driver is strongly recommended for the default Parakeet model
- About 4.4 GB for the installed app, plus about 2.5 GB for the first-run model download

This build is not yet code-signed. Windows SmartScreen may show **Unknown publisher**; choose **More info → Run anyway** after verifying the SHA-256 checksum supplied with the installer.
