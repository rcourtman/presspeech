# Presspeech 0.3.7

This patch keeps completed dictation bound to the window that was focused when
recording began.

## Safer text delivery

- Presspeech captures the destination before starting the audio engine, so a
  focus change during microphone startup cannot retarget the transcript.
- If focus changes while transcription or clipboard preparation is in
  progress, the transcript is copied to the clipboard for manual paste instead
  of being sent to the newly focused window.
- Clipboard paste rechecks the destination immediately before the paste event,
  and the Direct Unicode fallback rechecks it before every text chunk.
- A skipped automatic paste uses the existing visible and audible failure cue
  so the transcript is not silently left on the clipboard.

## Stability

- The optional recording HUD now stays hidden instead of crashing if macOS
  temporarily reports no available displays during sleep or display
  reconfiguration.

Audio and transcription remain local. Transcript text is not written to the
diagnostic log.
