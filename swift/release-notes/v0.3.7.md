# Presspeech 0.3.7

This update keeps completed dictation bound to its original window and makes
setup, recovery, and core controls easier to reach without relying on a visible
menu-bar item or the default hotkey.

## Safer text delivery

- Presspeech captures the destination before starting the audio engine and
  rechecks it before every automatic paste path.
- If focus changes while Presspeech is recording, transcribing, or preparing
  the clipboard, the transcript is copied for manual paste instead of being
  sent to the newly focused window.
- The menu-bar item keeps the **Copied — press ⌘V to paste** recovery action
  visible until the next dictation, even when transcript history is disabled.
  The recording indicator and VoiceOver announce the same recovery state.

## Setup and recovery

- Setup Checklist now tracks the speech model, audio input, each permission,
  and the hotkey independently, with a retry or grant action beside the step
  that needs attention. The window is resizable and scrolls on smaller screens.
- Opening Presspeech again while it is already running brings Setup Checklist
  forward instead of silently doing nothing.
- **Show in Dock** provides a persistent alternative when the menu-bar item is
  hidden by a notch or a crowded menu bar. Its Dock menu exposes dictation,
  Settings, support, and recovery controls; the standard application menu also
  provides Settings and Command-comma while Dock mode is enabled.
- If macOS has registered Launch at Login but still needs approval, the setting
  says so and opens the relevant System Settings pane instead of turning the
  registration off.

## Accessibility and controls

- Named **Start Dictation** and **Stop and Transcribe** menu actions provide a
  hotkey-free path and can be invoked with macOS Voice Control.
- The menu-bar control exposes loading, ready, recording, transcribing, and
  recovery states to VoiceOver.
- The recording indicator follows Reduce Motion, Reduce Transparency,
  Increase Contrast, and Differentiate Without Color as those settings change.
- Standard Edit and Window menus provide Undo, Cut, Copy, Paste, Select All,
  Close, Minimize, Zoom, and window discovery with the usual keyboard commands.
- Dictation recovery instructions are announced to VoiceOver rather than being
  available only as a visual or audible cue.

## Dictionary usability

- Large Dictionary & Shortcuts collections now open in a searchable manager
  with keyboard selection plus add, edit, and multi-item delete controls,
  instead of expanding into an impractically long menu.
- Double-clicking a rule opens it for editing, and a native shortcut menu puts
  Edit and multi-item Delete beside the selected rows for pointer and VoiceOver
  users. Truncated table cells expose their complete value in a tooltip.

## Stability

- The optional recording HUD now stays hidden instead of crashing if macOS
  temporarily reports no available displays during sleep or display
  reconfiguration.

Audio and transcription remain local. Transcript text, dictionary contents,
and shortcut contents are not written to the diagnostic log.
