# Presspeech 0.3.2

This patch makes the opt-in clipboard restoration path safer and more
reliable across applications with different paste timing.

## Clipboard reliability

- Presspeech now waits longer after posting Command-V before restoring the
  previous clipboard, giving slower target applications time to consume the
  dictated text.
- Temporary transcript clipboard entries stay on the current Mac and carry
  standard transient markers, so cooperating clipboard managers do not retain
  text that exists only long enough to paste.
- Clipboard writes are assembled before Presspeech takes ownership, and stale
  snapshots are discarded if another application changes the clipboard. When
  safe restoration is not possible, Presspeech leaves the dictated text in
  place instead of risking clipboard data loss.

## Speech model

The current FluidAudio candidates were re-evaluated on an expanded public
speech corpus. Parakeet TDT v3 remains the production model because it still
delivers the best accuracy and latency for Presspeech's push-to-talk workflow.
There is no speech-model migration in this release.

No audio, transcripts, settings, or clipboard contents leave the Mac.
