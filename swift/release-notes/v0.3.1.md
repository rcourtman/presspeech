# Presspeech 0.3.1

Presspeech now uses its own identity consistently across the app bundle,
preferences, correction documents, Application Support data, Homebrew
tap, and release tooling.

## Upgrade notes

- Saved preferences, hotkey choices, local dictionary rules, correction
  sync configuration, and interrupted-audio recovery state migrate
  automatically on first launch.
- macOS privacy grants cannot be transferred between bundle identifiers.
  Setup Checklist opens automatically so you can grant Microphone,
  Accessibility, and Input Monitoring once to the current Presspeech
  identity.
- The Homebrew install and update command is now
  `brew update && brew upgrade --cask rcourtman/presspeech/presspeech`.

No audio, transcripts, settings, or migration data leave the Mac.
