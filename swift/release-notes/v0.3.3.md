# Presspeech 0.3.3

This patch makes the dictation hotkey recover cleanly when Presspeech is not
yet able to start another recording, and improves privacy-safe troubleshooting
for hotkey permission problems.

## Hotkey reliability

- In toggle mode, a press received while the model is still loading or a
  transcription is in progress no longer consumes the next valid press. As
  soon as Presspeech is ready, the next press starts recording normally.
- Presspeech now records whether the macOS keyboard event tap is actually
  delivering events, helping distinguish a stale Input Monitoring grant from
  an unused hotkey.
- Diagnostics can identify an unmatched modifier key without recording
  ordinary keycodes or any typed text.

There is no speech-model migration in this release. Audio and transcripts
remain on the Mac, and transcript text never enters the diagnostic log.
