# Presspeech 0.3.8

This update fixes audio capture when input and output hardware use different
sample rates, strengthens automatic text delivery, and adds configurable
macOS hotkey combinations.

## Audio reliability

- The capture tap now reads the selected microphone's hardware format instead
  of inheriting the output device's rate. This prevents apparently successful
  recordings from producing empty audio when, for example, a 48 kHz microphone
  is used alongside 44.1 kHz output.
- A capture that returns no samples now points diagnostics toward an input-rate
  mismatch instead of looking like an accidentally short key press.

## Safer text delivery

- Presspeech preserves the frontmost process and, where the target exposes it,
  the exact focused window from recording through automatic paste. Apps that
  do not publish an Accessibility-focused window can still use automatic paste
  without weakening checks available for apps that do.
- Automatic clipboard restoration and its delay presets are retired: a timer
  cannot establish that a slow destination has consumed the paste. The new
  **Keep Previous Clipboard for Manual Restore** option requires a fresh opt-in,
  including for users who previously enabled automatic restoration.
- With that option enabled, a complete previous clipboard snapshot stays only
  in memory for up to five minutes. After checking that the latest dictated
  text arrived, choose **Restore Previous Clipboard…** and explicitly confirm.
  Cancel is the default; confirmation is not an operating-system acknowledgement.
- Consecutive dictations preserve the original snapshot and original deadline,
  which includes time asleep. Expiry, newer clipboard ownership, disabling the
  option or quitting discards the snapshot without an automatic rewrite.
  Clipboard ownership is checked after focus lookups and immediately before
  paste; a newer copy stops delivery. A stale confirmation cannot restore a
  different dictation's offer, and a failed restore never retries another write.
- Update checks accept only releases that GitHub marks immutable.

## Flexible hotkeys

- Record Hotkey can now save combinations using Command, Control, or Option
  with another key, with optional Shift, alongside the existing right-side
  modifier and function-key choices.
- Complete combinations persist across restarts and work in hold or toggle
  mode. Unsafe shortcuts and ordinary unmodified typing keys remain blocked,
  and a binding that cannot be saved rolls back to the previous hotkey.

Audio and transcription remain local. Transcript text and clipboard contents
are not written to the diagnostic log, and the global listener does not record
ordinary typed keys.
